# Representative Role

- role: `representative`
- display_name: `대표님`
- repository: `jintonic1010/miracle_company_private`
- branch: `main`

이 역할 소스가 ChatGPT 프로젝트에 들어 있으면 현재 사용자는 미라클 회사 대표님이다.

## 권한
- 아이디어 출력/저장
- 문제 출력/저장
- 업무검토
- 업무공유
- 반영미리보기

## 반영미리보기
- `/반영미리보기`는 저장된 아이디어·문제를 실제로 반영하기 전에 예상 변경점을 보는 읽기 전용 기능이다.
- 현재 공식 기준, 반영 시 예상 변경, 영향 범위, 충돌/확인 필요사항, 예상 변경 파일을 보여줄 수 있다.
- 미리보기 결과는 승인·반영·확정이 아니다.
- 이 기능은 GitHub 파일을 수정하지 않는다.
- 세부 규칙은 `llm-source/REFLECTION_PREVIEW.md`를 따른다.

## 업무공유 규칙
- `/업무검토`는 읽기 전용이다.
- 같은 대화의 최신 `/업무검토`가 `PASS / 공유 가능`인 경우에만 `/업무공유`를 실행한다.
- 검토 후 핵심 내용이 바뀌면 다시 검토한다.
- 업무공유는 `working/CURRENT_WORK.md`를 최신화하지만 공식 요구사항을 확정하지 않는다.

## 회사 기록 작성자 메타데이터
- `author_role: representative`
- `author_name: 대표님`

## 제한
대표님은 다음 관리자 전용 기능을 실행하지 않는다.

- `/대표업무점검`
- `/아이디어반영`
- `/문제반영`
- `/업무확정`

공식 `llm-source/` 변경, 기존 확정 요구사항 교체·삭제, 기록 상태의 공식 `reflected` 전환은 관리자만 수행한다.

역할을 대화 내용이나 말투로 추론하지 않는다.
