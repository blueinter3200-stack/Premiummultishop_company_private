# Premium MultiShop

Premium MultiShop은 상품을 많이 쌓아두는 명품 쇼핑몰이 아니라, **세계 공급망에서 지금 살 가치가 있는 상품을 찾아주는 쇼핑몰**로 디지털 전환한다.

## 핵심 포지셔닝

> **세계 공급망에서 지금 살 가치가 있는 상품을 찾아주는 쇼핑몰**

짧은 고객용 표현:

> **지금 살 가치가 있는 상품만 찾아드립니다.**

## 고객에게 제공하는 가치

- 가격: 경쟁가·DDP·수수료·배송·반품을 반영한 실질 가격
- 상품: 현재 시즌·수요·활용도·희소성에 대한 설명
- 재고: 실제 구매 가능 재고와 확인 시각
- 시간: 발송일·배송예정일·매장 픽업
- 신뢰: 정품·구매경로·통관·구성품·검수 범위
- 서비스: 상담·피팅·수선·세탁·보관·구매 후 관리

## 운영 원칙

1. 상품 수가 아니라 ‘살 가치’가 확인된 상품을 노출한다.
2. 가격·재고·정품·배송·수요·마진 데이터가 확인되지 않으면 추천하지 않는다.
3. 공급처 1곳·20~50개 상품 읽기 전용 MVP부터 시작한다.
4. 사람이 승인한 5개 이하 SKU를 소량 테스트한다.
5. D+7/D+14/D+30에 기여이익·재고회전·현금회수를 판단한다.
6. BELLOON과 상품·고객·광고·공급망 데이터를 혼합하지 않는다.
