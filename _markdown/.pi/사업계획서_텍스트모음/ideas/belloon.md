## 아이디어 분류

### 1. 해외 바이어용 OEM·ODM / PB
- UAE·중동 유통사 대상 3~5 SKU 소량 테스트 제안.
- 멀티브랜드 소싱·상품개발사에는 PB 공동기획 가능성을 검증.
- 판단 전제: MOQ·목표 도매가·물류·등록 책임·결제조건 확인 전에는 발주·독점 제안 금지.
- 관련 원자료: [[../research/belloon-buyer-sourcing-2026-08-12|해외 바이어 소싱 브리핑]], [[../research/belloon-linkedin-sourcing-ops|LinkedIn 바이어 소싱 운영 표준]]

### 2. 한국 브랜드 수권 유통
- 국가·채널별 비독점 도입 가능성을 우선 검토.
- 계약 전 `공식 총판`, `독점`, `전 세계 수권` 표현을 사용하지 않는다.
- 관련 검토 기록: [[../plans/contracts|계약 검토]]

### 3. 자체 브랜드·검증형 출시
- 미충족 문제를 처방·사용감·패키지 개선으로 정의하고 소량 검증.
- Gate 0 권리·규제 → Gate 1 시장 → Gate 2 제품·원가 → Gate 3 소량 판매 순서로 진행.
- 수익성·재고·규제 데이터가 없으면 아이디어 단계로 유지한다.
