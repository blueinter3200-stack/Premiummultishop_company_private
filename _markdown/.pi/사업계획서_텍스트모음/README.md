# 사업계획 관련 텍스트 모음

`BusinessVault/`에서 사람이 읽는 사업 관련 Markdown 문서만 복사한 폴더입니다.

## 포함

- 사업 계획·전략·검토 문서 (`plans/`)
- 시장·경쟁사·공급망·바이어 조사 (`research/`)
- 사업 아이디어 (`ideas/`)
- 사업별 시장 인덱스 (`market/`)
- 전체 인덱스, 의사결정 로그, 프로젝트 추적기

## 제외

- `.agents/`, `.claude/skills/` 등의 AI 스킬
- Obsidian 설정과 플러그인 (`.obsidian/`)
- TaskNotes 안내와 생성 뷰
- 개인 일지 (`HermesWiki/`)
- 대화 기록, 캐시, 로그, 실행 파일, 자격증명
- 빈 파일과 보관 정책 파일

원본 파일은 이동하거나 수정하지 않았습니다. 이 폴더의 파일은 원본과 같은 하위 구조와 내용을 유지한 복사본입니다.
