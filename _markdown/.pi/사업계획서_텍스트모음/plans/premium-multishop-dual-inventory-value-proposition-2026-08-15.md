# Premium MultiShop 이중 재고·이중 가치제안 운영전략

- 결정일: 2026-08-15
- 사업: Premium MultiShop
- 상태: 대표 방향 반영 / SKU별 원가·수요·배송 데이터 검증 필요

## 1. 핵심 결정

Premium MultiShop은 재고와 고객가치를 두 체계로 분리한다.

```text
홍콩·해외 공급망
→ 해외 주문형·가격경쟁·희소상품

한국 창고 보유 재고
→ 정품검증·실물확인·빠른배송·반품·A/S
```

두 상품군을 같은 가격·배송·고객약속으로 운영하지 않는다.

## 2. 상품군별 가치제안

| 구분 | 해외 주문형 | 한국 창고 보유 재고 |
|---|---|---|
| 핵심고객 | 가격·희소성·선택권 중시 | 속도·신뢰·실물확인 중시 |
| 경쟁요소 | 해외 매입가·희소 사이즈·구색 | 즉시성·정품증빙·검수·상담 |
| 배송 | 예상일·통관·DDP 조건 표시 | 출고마감·실배송일 표시 |
| 가격 | 낮은 가격 또는 희소성 프리미엄 | 서비스 포함 가격·합리적 프리미엄 가능 |
| 재고 | 선매입 최소화·주문 후 조달 | 핵심 SKU·인기 사이즈 선확보 |
| 고객약속 | 가격과 공급조건 투명화 | 빠른 배송·실물·반품·A/S 책임 |
| 콘텐츠 | 공급처·배송·가격 비교 | 실물 사진·검수기록·착용·포장 영상 |
| 중단조건 | 공급·통관·배송·반품 리스크 증가 | 장기재고·마진 하락·배송 SLA 미달 |

## 3. 상품 페이지 필수 표시

모든 상품에 재고 유형을 명확히 표시한다.

### 국내 보유 재고

- `국내 창고 보유`
- `실물 확인일시`
- `검수 완료 여부`
- `출고 마감시간`
- `예상 배송일`
- `구성품·상태`
- `반품·교환·A/S 조건`
- `매장·예약 쇼룸 확인 가능 여부`

### 해외 주문형

- `해외 공급처 주문형`
- `공급처 확인일시`
- `예상 출고일·도착일`
- `통관 주체·관부가세 부담자`
- `DDP 포함 범위`
- `주문취소·반품·환불 조건`
- `정품·구매경로·구성품 증빙`
- `배송지연 시 책임과 보상 기준`

## 4. 가격정책

### 국내 보유 재고

최저가가 아니라 다음 서비스가 포함된 가격으로 운영한다.

- 실물 검수
- 빠른 배송
- 사이즈·핏 상담
- 정품 증빙
- 국내 반품 처리
- 수선·A/S 안내
- 예약 쇼룸·픽업

단, 서비스 프리미엄은 실제 원가·반품·상담·A/S 비용을 반영해 산정한다. 가격 프리미엄을 임의로 부여하지 않는다.

### 해외 주문형

```text
판매가
- 해외 매입가
- 홍콩 입출고·보관비
- 국제운송·DDP/통관비
- 환율·결제수수료
- 플랫폼 수수료
- 광고·할인비
- CS 비용
- 반품·환불·정품분쟁 충당금
= 주문당 기여이익
```

150달러 면세를 사업자의 재판매 가격경쟁 핵심값으로 확정하지 않는다. 거래유형·수입자·통관명의·고객 자가사용 여부가 확인된 경우에만 상품별로 검토한다.

## 5. 재고 배분 규칙

### 한국 창고에 보유할 상품

- 최근 판매속도가 확인된 상품
- 인기 브랜드·핵심 사이즈
- 빠른 배송이 구매결정에 큰 상품
- 고가·검수 민감 상품
- VIP·예약 쇼룸 수요가 있는 상품
- 반품·A/S를 직접 통제해야 하는 상품

### 홍콩·해외 주문형으로 둘 상품

- 롱테일 상품
- 희소 사이즈·색상
- 국내 수요가 불확실한 상품
- 가격 차이가 완전원가 기준으로 유효한 상품
- 공급처 정품·재고·배송·반품이 검증된 상품
- 한국 선입고 시 장기재고 위험이 큰 상품

## 6. 고객 세그먼트

- `가격중시`: 해외 주문형·가격비교·예상 배송일
- `속도중시`: 국내 보유 재고·당일/익일 출고
- `신뢰중시`: SKU 여권·정품증빙·실물 영상·예약 쇼룸
- `VIP`: 국내 보유 재고 우선·선공개·사이즈 보관·A/S 우선
- `희소상품 탐색`: 해외 주문형·재입고 알림·개별 상담

가격중시 고객에게 국내 재고를 무조건 할인하지 않는다. 속도·신뢰중시 고객에게 해외 주문형을 최저가만으로 권하지 않는다.

## 7. 90일 테스트

### 0~30일

- 국내 보유 재고 10~20개 SKU 유형화
- 해외 주문형 3~5개 SKU 후보 선정
- 상품 페이지 재고유형 표시
- 주문·상담·배송·반품 ID 연결
- 고객에게 가격·속도·신뢰 중 우선요소 질문

### 31~60일

- 국내 보유 재고의 빠른배송·검수 콘텐츠 테스트
- 해외 주문형의 가격·희소성 콘텐츠 테스트
- 카카오 상담에서 고객 우선가치 기록
- 채널별 전환율·할인율·배송일·반품률 측정

### 61~90일

- 상품 유형별 기여이익 비교
- 국내재고 회전일·장기재고 계산
- 해외주문형 배송지연·취소·환불 측정
- 창고 보유와 해외 주문형의 현금회수 비교
- 확대·보류·중단 결정

## 8. 공통 하드스탑

- 순마진율 12% 미만: 보류
- 예상 월 순이익 50만 원 미만: 보류
- 회수기간 6개월 초과: 보류
- 데이터 신뢰도 0.70 미만: 검증 보류
- 법적 안전도 4/5 미만: 보류
- 재고회전일 90일 초과: 추가 발주 보류
- 해외 리드타임 45일 초과: 보류
- 정품·통관·A/S 증빙 불가: 판매·발주 금지
- 국내재고 출고약속 반복 미준수: 해당 SKU 운영 중단
- 해외 공급처 품절·가격급변 반복: 판매중지·사람 검토

## 최종 운영 원칙

Premium MultiShop의 경쟁력은 모든 상품을 싸게 파는 것이 아니다.

```text
가격이 중요한 고객에게는 경쟁력 있는 해외 주문형 상품
속도와 신뢰가 중요한 고객에게는 국내 검증 재고와 서비스
```

를 정확히 제공하는 것이다.

이 구조는 해외 공급망의 가격·구색과 기존 매장의 신뢰·검수·빠른 배송을 동시에 활용하는 방식이다. 단, 상품별 완전원가와 고객별 실제 전환 데이터가 확인되기 전까지는 전체 상품 확대가 아니라 소량 테스트로 운영한다.
