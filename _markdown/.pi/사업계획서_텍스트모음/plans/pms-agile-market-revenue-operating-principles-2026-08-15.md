# Premium MultiShop 애자일 시장·수익 운영 원칙

- 기준일: 2026-08-15
- 적용 사업: Premium MultiShop 전용
- 목적: 경쟁·유사 업체보다 빠르게 시장을 감지하고, 작은 비용으로 검증하며, 수익성이 확인된 영역만 확대

## 1. 운영 선언

Premium MultiShop은 단순히 상품을 많이 판매하는 쇼핑몰이 아니라 **세계 공급망에서 지금 살 가치가 있는 상품을 빠르게 발견·검증·제안하는 커머스 운영 플랫폼**으로 운영한다.

속도는 무분별한 자동화가 아니라 다음 5가지를 줄이는 것으로 정의한다.

- 시장 신호를 발견하는 시간
- 상품·공급·원가를 검증하는 시간
- 승인에서 실행까지의 대기시간
- 실패를 감지하는 시간
- 실패 후 재고·현금을 회수하는 시간

## 2. 모든 업무의 공통 루프

```text
Sense → Frame → Test → Measure → Decide → Scale / Stop → Learn
시장감지  문제정의  소량검증   측정      판정        확대/중단      학습
```

각 실행에는 반드시 다음을 붙인다.

- 가설
- 대상 고객
- 테스트 SKU·예산·기간
- 담당자
- 성공 KPI
- 중단 기준
- 최대손실
- 다음 검토일

## 3. 경쟁우위의 정의

가격·상품 수·할인율만으로 경쟁하지 않는다. 방어 가능한 경쟁우위는 다음의 결합이다.

1. 신뢰 가능한 정품·구성품·검수
2. 실제 재고·빠른 배송·정확한 안내
3. 일대일 상담과 사이즈·스타일 제안
4. 구매 후 A/S·수선·관리
5. 공급망·가격·수요 데이터를 빠르게 학습하는 능력
6. 구매 후 고객을 재구매·교차판매로 연결하는 관계 자산

## 4. 속도와 통제의 균형

### 빠르게 해도 되는 일

- 공개 데이터 수집
- 경쟁 가격·상품·콘텐츠 모니터링
- 키워드·상품 후보 생성
- 콘텐츠 초안 작성
- 이상치·재고·가격 경보
- 기존 승인 규칙 내 리포트 자동화

### 반드시 승인하는 일

- 신규 상품 공개
- 가격·할인 변경
- 광고 예산 증액
- 대규모 CRM 발송
- 발주·사입
- 환불·고액 고객 조치
- 고객 병합
- 법적·정품·통관 판단

## 5. 시장 감지 체계

| 주기  | 감지 항목                               | 결과물            |
| --- | ----------------------------------- | -------------- |
| 일간  | 검색어 급증, 경쟁 가격, 품절, 문의, 장바구니, 공급처 변화 | 시장 신호 큐        |
| 주간  | 키워드·상품·콘텐츠·광고·CRM 성과                | 테스트 후보와 중단 후보  |
| 월간  | 브랜드·카테고리·채널·고객 LTV·재고회전             | 바잉·채널·고객 전략 수정 |
| 분기  | 경쟁사 포지셔닝·공급망·매장 구조·수익모델             | 사업 구조 재평가      |

시장 신호는 판매량으로 단정하지 않고 **가설**로 등록한다.

## 6. 애자일 테스트 원칙

- 테스트 SKU: 3~5개
- SKU당 수량: 1~2개
- 1차 반응: D+7 또는 14일
- 손익·재고 검증: D+30
- 재구매·장기 가치: D+90
- 실제 입력이 없으면 수익성은 `검증 불가`
- 하드스탑 위반 시 확대가 아닌 중단·회수

## 7. 경영 KPI 우선순위

1. 현금회수기간
2. 월 순이익
3. 순마진율
4. 재고회전일
5. 재구매율·고객 LTV
6. 채널별 기여이익
7. 시장 감지부터 테스트 승인까지의 리드타임
8. 실패 감지·재고회수까지의 리드타임
9. 콘텐츠·광고·CRM의 기여이익
10. 데이터 신뢰도·예외 처리시간

조회수·팔로워·상품 수·광고 클릭만으로 성과를 판단하지 않는다.

## 8. 의사결정 출력 형식

모든 시장·경쟁·상품 분석은 다음 순서로 작성한다.

1. 한 줄 결론: 실행 / 테스트 / 보류 / 중단
2. 확인된 사실과 기준일
3. 검증 불가·가설·대표 결정 필요 항목
4. 경쟁 대비 우위와 약점
5. 예상 손익·현금·재고 영향
6. 테스트 설계
7. 성공·중단 기준
8. 실행 담당·마감·KPI
9. 다음 검토일

## 9. 금지

- 경쟁사 최저가 자동 추종
- 조회수만으로 수요 확정
- AI 추정만으로 발주
- 공급처·정품·DDP 미확인 거래
- 동의 없는 CRM
- 실패한 테스트의 자동 확대
- 수익성 없는 매출을 성장으로 포장
- 확정되지 않은 수권·독점·총판 표현
- 데이터가 없는데 숫자를 채워 넣기
