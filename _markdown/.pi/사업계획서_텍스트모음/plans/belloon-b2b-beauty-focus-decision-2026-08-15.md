# BELLOON 화장품 B2B 집중 결정

- 결정일: 2026-08-15
- 사업: BELLOON 글로벌 뷰티
- 관련 사업: Premium MultiShop과 분리
- 상태: 대표 결정 반영

## 결정

화장품 사업은 Premium MultiShop에서 분리하고 BELLOON을 통해 다음 두 축에 집중한다.

1. 한국 브랜드 수권 기반 B2B 유통
2. OEM·ODM 제조 기반 해외 바이어 B2B 공급

YesStyle 등 해외 소매 플랫폼 API·Affiliate·주문중개를 Premium MultiShop의 화장품 핵심사업으로 확장하지 않는다.

## 사업 구조

```text
한국 브랜드 수권 또는 OEM·ODM 상품기획
→ 상표·처방·판매권·국가별 규제 확인
→ 해외 B2B 바이어 발굴
→ 샘플·MOQ·완전원가·납기 검증
→ 계약·수출·초도 발주
→ 반복 발주·재구매·국가 확장
```

## 우선순위

- 현금회수기간
- 순이익·순마진
- 바이어 재주문
- 국가별 합법 판매 가능성
- 재고 위험 축소
- 매출 확대

## 실행 원칙

- 계약서 확인 전 공식 총판·독점·수권 표현 금지
- 상표권·처방권·판매권 귀속 확인
- 국가별 화장품 등록·신고·라벨·광고 검토
- 제조사 2곳 이상 비교
- 최대 5 SKU 또는 300만원 이하 소량 검증
- 샘플·MOQ·성분·시험자료·패키지·납기 확인
- 수익성 계산은 margin_check.py 사용
- 월 순이익 50만원 미만, 순마진율 12% 미만, 법적 안전도 4/5 미만이면 보류

## 분리 규칙

- BELLOON: OEM·ODM·브랜드 수권·B2B 바이어·화장품 규제·수출·재구매
- Premium MultiShop: 명품 의류·신발·잡화·병행수입·직수입·상담·검수·A/S
- 상품·고객·재고·손익·CRM 데이터를 두 사업 사이에 혼합하지 않는다.

## 다음 검증

1. 브랜드 수권 후보와 OEM·ODM 후보를 분리한 공급망 목록 작성
2. 국가별 B2B 바이어와 채널별 수입·규제 조건 확인
3. 대표 SKU 3~5개를 대상으로 완전원가와 MOQ 계산
4. 바이어 샘플·초도주문·재주문 조건 확인

## 보류 조건

- 바이어의 실제 법인·수입자·결제능력 미확인
- 브랜드 수권·OEM 계약의 권리범위 불명확
- 상표권·처방권·규제 책임 불명확
- MOQ와 현금회수기간이 하드스탑 초과
- 수출·라벨·광고·제품등록 요건 미확인
