# Premium MultiShop 실시간 공급상품·판매 퍼널 설계

- 기준일: 2026-08-13
- 사업: Premium MultiShop
- 상태: 설계 완료 / 공급처·API·고객 데이터 검증 필요

## 목표

정품·DDP·가격경쟁력·재고 연동이 검증된 해외 공급상품만 Cafe24 자사몰에 노출하고, 콘텐츠·SEO·Meta·동의 기반 카카오 CRM·오프라인 상담을 연결해 광고비·수수료·배송·반품을 차감한 실제 기여이익을 만든다.

## 사용자 제공 자산과 검증 상태

- 카카오 친구 약 20,000명: 사용자 제공값. 활성·광고성 메시지 수신동의·중복·철회 여부 검증 전.
- 자사몰/Meta 픽셀 기반 고객 약 80,000명: 사용자 제공값. 활성·매칭 가능·동의·이벤트 품질 검증 전.
- 따라서 일괄 발송·대규모 광고를 전제로 하지 않고 세그먼트별 소량 테스트를 기본으로 한다.

## 운영 퍼널

```text
공급처 재고/API 확인 → SKU 수익성·정품·DDP 검증 → 5개 이하 자사몰 테스트 등록
→ SEO·실물/비교 콘텐츠 → 매장·쇼룸 상담/픽업 → 동의 고객 카카오 선공개
→ Meta 카탈로그·리타게팅 → 구매 → A/S·관리·재구매
→ D+7/D+14/D+30 손익·재고회전 판정
```

## 신규 SKU 공개 승인 기준

- 브랜드·모델·시즌·품번·색상·사이즈 확정
- 공급처 법인·공급망·인보이스·정품/통관 증빙 확인
- DDP/DAP/EXW 구분과 한국 도착 총원가 확인
- 국제배송·반품·클레임·A/S 책임 확인
- 재고 갱신 주기, 가격 변동, 품절·취소 처리 확인
- SKU 매핑과 재고 확인 시각 기록
- 경쟁가·최저 판매가·목표 기여이익 계산
- 상품 이미지·문구 사용권 확인
- 출고일·예상 도착일·반품 조건 공개

하나라도 누락되면 공개 등록이 아니라 `검증 보류`다.

## 가격·재고 표시 원칙

- `공급처 확인 시각`, `국내/해외 재고`, `예상 발송일`, `DDP 포함 여부`를 표시한다.
- API 오류·stale inventory·가격 급변 시 자동 공개를 중지한다.
- 최저 판매가는 DDP 실원가 + 국내 처리비 + 수수료 + 반품충당 + 고객획득비용 + 목표 기여이익으로 계산한다.
- 경쟁사보다 싸다는 주장보다 가격 기준일·구성비용·배송 조건을 명시한다.

## 콘텐츠 템플릿

1. 한 줄 구매 이유
2. 브랜드·모델·품번·시즌·색상
3. 소재·핏·사이즈와 실측
4. 실물 촬영·재고 위치·확인 시각
5. 정품·통관 증빙과 검수 범위
6. 오늘 발송 마감·예상 도착일
7. 매장 방문·피팅·예약·픽업 가능 여부
8. 반품·교환·A/S 조건
9. 가격 비교 기준일과 혜택
10. 문의·구매 CTA

공급처 이미지·문구의 무단 복제와 과장된 ‘무조건 정품’ 문구는 사용하지 않는다.

## 채널 운영

- 자사몰: 정상가·고객 데이터·상세 콘텐츠·재구매 중심
- Meta: 신규 발견, 상품 조회·장바구니 이탈 리타게팅. Pixel/CAPI와 동의·카탈로그 상태 확인 전 대규모 집행 금지.
- 카카오: 최근 구매·브랜드 관심·VIP·장바구니/조회·휴면 등 동의 세그먼트별 선공개/재활성화. 전체 2만 명 일괄 발송 금지.
- 매장·쇼룸: 고가상품 피팅·정품/소재 상담·예약·픽업·콘텐츠 촬영.
- KREAM: 표준 SKU 수요 확인·보유재고 회수용 보조 채널.

## MVP

### Phase 0: 공급처 문서·샘플 검증
- 공급처 1곳 우선
- API/피드 문서, DDP 견적, 정품·인보이스, 반품조건 확보
- 한국행 소량 샘플 통관·배송 검증

### Phase 1: 읽기 전용 연동
- 상품 20~50개
- 재고·가격 조회만 연동
- Cafe24 비공개/테스트 상품
- 수동 데이터와 자동 데이터 대조

### Phase 2: 승인 기반 공개·주문
- 5개 이하 SKU 공개
- 사람이 가격·재고·증빙 승인
- 주문·취소·배송은 수동 확인 후 제한적 자동화

### Phase 3: 퍼널 테스트
- Meta와 카카오에서 세그먼트별 소량 테스트
- SEO 콘텐츠와 매장 상담 연결
- D+7·D+14·D+30 측정

### Phase 4: 확대
- 공급처별 SLA·가격·반품·공헌이익 통과 시에만 추가 공급처/API 확대

## 핵심 KPI

- 재고 동기화 성공률·stale inventory 비율
- 품절 오노출·가격 오류·주문 중복 건수
- 상품 조회·장바구니·상담·구매 전환율
- 채널별 CAC와 기여이익
- 할인·수수료·배송·반품 차감 후 SKU 공헌이익
- 재고회전일·현금회수기간·취소율·반품률
- 카카오 수신거부율·Meta 이벤트 품질

## 중단 조건

- 정품·통관·DDP·반품 책임을 서류로 확인하지 못함
- 재고/가격 오류나 주문 후 품절 반복
- 광고·메시지 비용 포함 기여이익 0 이하
- 목표 순마진 미달 또는 가격 급변
- API 오류로 잘못된 상품·가격·재고 노출
- 고객 광고/메시지 동의 근거 불명확
- 공급처 반품·환불·클레임 SLA 불명확
