# Premium MultiShop 신뢰상품 `두 겹 약속™` 설계

- 조사일: 2026-08-15
- 사업: Premium MultiShop
- 근거: 대표님의 전국 매장 운영 현장 관찰 + 경쟁사·한국 공식자료 조사
- 상태: 운영 설계 확정 / 법률·약관 검토와 30일 소량 테스트 필요

## 1. 결론

Premium MultiShop이 고객에게 제시해야 할 뚜렷한 무엇은 단순한 `정품 보장` 문구가 아니다.

권장 신뢰상품은 다음 세 요소를 결합한 **`두 겹 약속™`**이다.

```text
SKU 상품여권
+ 책임거래 헌장
+ 배송·통관·반품·A/S·보상 프로토콜
```

고객은 구매 전에 다음을 확인할 수 있어야 한다.

- 누가 상품을 보유하는가
- 어떤 경로로 조달했는가
- 누가 검수했는가
- 실제 상품의 상태는 어떤가
- 언제 출고되는가
- 통관 문제가 생기면 누가 책임지는가
- 반품·환불은 어떻게 처리되는가
- 정품 분쟁 시 누가 비용을 부담하는가
- A/S는 공식 서비스인지 판매자 접수인지
- 문제가 해결되지 않으면 어떤 보상을 받는가

## 2. 대표 현장 관찰의 전략적 해석

전국 오프라인 매장 운영 경험에서 확인된 고객의 핵심 니즈는 매장 공간 자체가 아니라 다음이었다.

- 안전한 거래
- 직접 상담
- 상품 확인
- 문제 발생 시 찾아갈 수 있는 판매자
- 책임·보상에 대한 확신

온라인 소비자는 매장을 포기한 것이 아니라, 매장에서 확인하던 신뢰를 온라인의 증거·약속·처리기록으로 확인하려는 것이다.

```text
오프라인 신뢰
= 매장·직원·실물·대면응대·사업자 존재감

온라인 신뢰
= 상품증거·판매자 책임·배송약속·반품규칙·보상프로토콜·상담기록
```

## 3. `두 겹 약속™` 상품 구성

### READY — 이미 확인된 상품

대상: 한국 창고 보유 재고

고객 약속:

- 국내 실물 보유
- 실물 확인일시 공개
- 출고 전 검수
- 구성품·상태 공개
- 검수 완료 후 출고
- 국내 반품센터
- 빠른 배송 기준 공개

상품 화면 예시:

> `READY / 국내 실물 확인 / 영업일 기준 출고일 표시 / 출고 전 검수 / 국내 반품`

당일배송·익일배송은 실제 물류 데이터와 택배 계약을 확인한 상품에만 사용한다. 검증 전에는 `출고 예정일`로 표시한다.

### RARE — 희소하지만 책임이 명확한 상품

대상: 홍콩·해외 주문형 재고

고객 약속:

- 해외 공급처 확인일시
- 예상 조달기간
- 예상 국내 도착기간
- 재고 확정 시점
- 통관상 수입자
- 관세·부가세·통관수수료 부담자
- 조달 실패 시 처리
- 해외 반품 가능 여부와 비용
- 환율·국제배송비 변동 가능성

상품 화면 예시:

> `RARE / 해외 주문형 / 예상 조달 3~7일 / 예상 도착일 표시 / 통관·반품 책임자 표시`

`구매대행`이라는 명칭만으로 통관·환불·정품 책임을 회피하지 않는다. 실제 소유권·재고·가격·공급처 통제 구조에 따라 거래유형을 분류한다.

### CARE — 구매 후 관리

대상: READY·RARE 공통

구성:

- 브랜드 공식 A/S 가능 여부
- 판매자 접수 대행 여부
- 검증된 외부 수선처
- 무상·유상 범위
- 수선 예상기간
- 부품비·공임·배송비 부담자
- 세탁·보관·가죽·패딩 관리
- 재판매·보상판매 상담
- 구매 후 30·90·180일 관리 접점

공식 A/S와 판매자 자체 A/S를 상품페이지에서 명확히 구분한다.

## 5. 책임거래 헌장

고객이 주문 전에 확인할 책임 항목은 다음 8가지다.

1. **상품 식별** — 내가 사는 정확한 SKU는 무엇인가
2. **실물 상태** — 새상품·전시품·하자·구성품은 무엇인가
3. **정품 증거** — 어떤 자료와 절차로 확인했는가
4. **배송 약속** — 언제 출고되고 언제 도착하는가
5. **통관 책임** — 누가 수입자·납세자·통관 책임자인가
6. **반품·환불** — 사유별 비용·기한·환불일은 무엇인가
7. **분쟁·A/S** — 누가 어떤 절차로 해결하는가
8. **보상** — 약속 위반 시 어떤 구제를 제공하는가

## 6. 정품분쟁 프로토콜

경쟁사처럼 `200% 보상` 숫자만 강조하지 않는다. 판정 절차와 이행기한을 먼저 공개한다.

```text
접수
→ 해당 SKU 판매중지·재고 격리
→ 검수·출고·공급처 증거 보존
→ 1차 내부 검토
→ 공급처 자료 확인
→ 독립 감정 또는 전문기관 검토
→ 고객에게 결과·선택지 안내
→ 환불·교환·수선·기각
→ 공급처·SKU 등급 재평가
```

권장 내부 기준:

- 접수 후 1영업일 이내 절차 안내
- 고객에게 성급하게 정품 여부를 단정하지 않음
- 회사 검수 오류면 환불·배송비·감정비 부담 검토
- 증빙이 불충분하면 추가 판매 중지
- 판단이 장기화되면 고객에게 중간 진행상황과 선택지 제공
- 동일 공급처·모델 반복 클레임 시 발주 보류

- 해외 반품 주소와 비용

### 반품·환불 운영 원칙

한국 전자상거래법상 청약철회·환불 등 법정 권리를 임의로 축소하지 않는다. 해외배송·세일·주문제작이라는 이유만으로 일률적인 환불불가 문구를 사용하지 않는다.

- 단순변심·사이즈 문제와 판매자 귀책을 분리
- 상품 훼손·사용·오염·구성품 분실 기준을 사전 고지
- 반품 접수일·회수일·입고일·검수일·환불일 기록
- 판매자 귀책이면 반품·환불 비용 부담
- 환불 지연이 없도록 내부 처리기한 설정
- 구매대행의 상품대금·수수료·국제운송비·관세·부가세를 항목별 정산

## 8. `약속 회복 크레딧`

경쟁사의 무조건적 보상률을 복제하지 않고, 약속 위반을 등급화한다.

| 등급 | 예시 | 기본 처리 |
|---|---|---|
| P0 | 정상 처리 | 상태 안내 |
| P1 | 안내 누락·약속시간 임박 | 선제 안내·일정 재확인 |
| P2 | 판매자 처리 지연·오배송·검수 누락 | 배송비·반품비 부담 및 서비스 크레딧 검토 |
| P3 | 조달 실패·통관 문제·중대한 설명 불일치 | 즉시 환불 또는 대안상품 + 추가 보상 검토 |
| P4 | 정품 증빙 실패·중대한 신뢰 훼손 | 우선 환불·감정/배송비 처리·경영진 검토 |

현금보상·보상률·쿠폰은 대표 승인과 실제 원가 검토 후 확정한다. 모든 문제를 동일한 쿠폰으로 처리하지 않는다.

## 9. 고객 단일 책임 창구

고객이 플랫폼·해외 공급자·택배사 사이를 오가게 하지 않는다.

- Premium MultiShop이 1차 책임 창구
- CS 접수번호 발급
- 담당자·다음 답변일 표시
- 해외 공급처에 고객이 직접 연락하지 않음
- 배송사·공급처와의 클레임은 판매자가 처리
- 해결 지연 시 중간 진행상황 통지
- 분쟁 종료 후 재발방지 조치 기록

- 약속 회복 크레딧
- 구매 후 30·90·180일 관리

자율 약속도 상품페이지·약관에 공개하면 사업자의 계약상 약속으로 해석될 수 있으므로 실제 운영 가능한 범위만 채택한다.

## 13. 경쟁사와의 차별화

KREAM의 검수 카드·QR, 머스트잇의 200% 보상·케어, 발란의 배송 보상, 필웨이의 감정·보증서와 같은 요소는 이미 시장에 존재한다.

Premium MultiShop은 다음을 복제하지 않는다.

- 200% 보상 숫자 경쟁
- 모든 상품 당일배송
- 근거 없는 100% 정품 선언
- 검수 카드만 발급
- 공식 A/S와 판매자 A/S 혼용
- 고객을 플랫폼·공급처·택배사 사이에서 이동시키기

대신 다음을 만든다.

> **구매한 바로 그 상품의 조달·검수·상태·출고·반품·A/S·보상 이력을 하나의 상품여권과 주문 ID로 연결하는 판매자 책임 시스템**

## 14. 권장 포지셔닝 문구

> Premium MultiShop은 상품마다 조달 경로, 구성품, 검수 결과, 출고 전 상태를 기록합니다. 정품성에 이견이 생기면 고객에게 책임을 전가하지 않고, 당사가 회수·재검수·필요 시 독립 감정을 진행합니다. 배송·반품·A/S 조건은 상품별로 사전에 공개하며, 판매자가 고객의 단일 책임 창구가 됩니다.
