# Premium MultiShop 온라인 이커머스 전환 계획

> **사업 범위:** Premium MultiShop 전용. 명품 병행수입·직수입 상품의 온라인 중심 판매 전환을 기록한다. 다른 사업의 자료·링크·가정은 포함하지 않는다.
>
> **작성 기준일:** 2026-08-12 (사용자 지시 및 기존 위키·사업 스킬 확인 기준)
>
> **데이터 원칙:** 숫자 목표가 기존 자료에 없으면 임의로 만들지 않고 **대표 결정 필요**로 표시한다. 아래의 50%, 100%, 30% 등은 기존 `premium-multishop` 현재상태 문서에 이미 기록된 조건을 보존한 것이다.

## 1. 전환 배경과 목표

### 배경

- 최신 지시: 오프라인 매장 중심에서 온라인 이커머스 중심으로 전환하고, 기존 매장은 오프 또는 축소한다.
- 온라인은 판매 채널이 아니라 `콘텐츠·검색/접점 → 상담 → 구매 → 사후관리 → 재구매`를 연결하는 수익 루프로 운영한다.
- 기존 자료상 핵심 병목은 재구매와 채널별 순이익 분석이다. 매장 매출만 보지 않고 오프라인 상담 후 온라인 구매도 귀속한다.
- 온라인 이전 및 통합은 확정된 폐점 명령이 아니다. 고객 데이터, 손익, 물류, 임대차, 현금흐름을 확인하는 조건부 전환이다.

### 목표

1. 재고를 창고 겸 사무실에 통합·표준화해 포장·출고 속도와 재고 정확도를 높인다.
2. Cafe24 자사몰·스마트스토어/네이버·카카오의 역할을 분리해 채널별 기여이익을 측정한다.
3. 정품·통관·상품 상태 증빙, 실물 확인, 고관여 상담, A/S·수선·세탁 접수를 온라인 구매의 차별점으로 만든다.
4. 오프라인 고정비를 줄이되, 즉시 폐점으로 발생할 고객 이탈·재고 처분·원상복구 손실은 전환 게이트로 제한한다.
5. 매출보다 월 순이익, 순마진율, 현금회수기간, 재고회전일, 재구매율을 우선 관리한다.

## 2. 오프라인 매장 종료·축소 판단 기준과 단계

### 판단 기준

아래는 기존 위키의 서울 창고형 쇼룸 통합 조건을 전환 게이트로 채택한다. 미확인 항목은 대표 결정 전까지 폐점 근거로 사용하지 않는다.

- 충성고객 온라인 이전율 **50% 이상**
- 4개 매장 고객 데이터 백업률 **100%**
- CRM 핵심 기능 검수 완료
- 매장별 매출·매출총이익·고정비 확인
- 통합 전후 12개월 손익 비교
- 이전비·원상복구비·보증금 회수 일정 확인
- 통합 거점 임차료·인건비·물류비 산출
- 당일배송 가능지역과 비용 검증
- 폐점에 따른 예상 매출이탈 계산
- 통합 투자금이 가용현금의 **30% 이하**

기존 상태 문서의 원칙대로 2026-08-31 기준 온라인 이전율이 50% 미만이면 원칙적으로 연기한다. 예외는 통합 지연비용이 예상 고객 이탈손실보다 크다는 손익자료가 있을 때만 별도 대표 승인으로 검토한다.

### 단계

| 단계 | 운영 | 진입 조건 | 종료·중단 조건 |
|---|---|---|---|
| 0. 기준선 확보 | 매장별 매출·매출총이익·고정비, 재고, 고객 데이터, 임대차·원상복구 조건을 수집 | 데이터 담당자·자료 범위 확정 | 핵심 손익·계약 자료가 없어 폐점 판단 불가 |
| 1. 온라인 병행 | 온라인 판매·상담·출고를 늘리고 매장은 기존 고객 피팅·상담·재고회수에 활용 | 재고·주문·상담 귀속 방식 마련 | 배송·반품·정품 증빙이 안정되지 않으면 확대 보류 |
| 2. 축소·예약제 | 매장 영업시간·상시 진열을 줄이고 예약 방문 쇼룸으로 전환 | 이전율·고객 데이터·물류 검증, 임대차 검토 | 예약 수요·온라인 전환·고정비 개선이 확인되지 않으면 폐점 보류 |
| 3. 통합 거점 | 창고 겸 사무실 중심 운영, 예약 방문과 온라인 출고 병행 | 위 전환 게이트 전부 통과 및 대표 승인 | 손익·현금흐름·서비스 수준 악화 시 축소안 재검토 |

**즉시 폐점 금지:** 계약 해지, 폐점, 결제, 외부 발송은 이 문서 작성 범위에서 실행하지 않는다. 게이트 통과·대표 결정·계약 검토 후 별도 실행한다.

## 3. 창고 겸 사무실 및 예약 방문 쇼룸 운영 모델

### 창고 겸 사무실

- 단일 재고 원장을 기준으로 SKU·사이즈·상태·입고일·원가·판매채널 배정을 관리한다.
- 공간을 `입고·검수 / 판매 가능 재고 / 예약·촬영 / 포장 대기 / 출고 완료 / 반품·검수 보류 / A/S·수선 보류`로 구획한다.
- 사무실은 온라인 상담, 주문 확인, 정품·통관·상품 상태 자료 관리, CS·반품·A/S 접수의 운영 허브로 둔다.
- 고가품은 접근 권한, 보관 위치, 검수자, 출고 시 증빙을 기록한다. 보관·보험·보안 비용은 **대표 결정 필요**.

### 예약 방문 쇼룸

- 상시 매장이 아니라 사전 예약 고객만 방문하는 실물 확인·피팅·상담 공간으로 운영한다.
- 예약 시 고객, 희망 SKU, 방문 목적, 상담 담당자, 희망 시간, 구매·온라인 전환 여부를 기록한다.
- 방문 후 결제는 온라인 주문으로 연결할 수 있으나 채널 정책을 준수하고, 상담 기여를 별도 귀속한다.
- 쇼룸은 재고 전량 전시가 아니라 예약 SKU·고가/고관여 상품·콘텐츠 촬영 상품 중심으로 운영한다.
- 운영 시간, 예약 노쇼 기준, 현장 인력, 보안, 보험, 임차 조건은 **대표 결정 필요**.

## 4. 온라인 채널 우선순위와 역할

기존 자료에서 확인된 채널만 기록한다.

| 우선순위 | 채널 | 역할 | 핵심 측정 |
|---|---|---|---|
| 1 | Cafe24 자사몰 | 고객 데이터 소유, 정상가격 판매, VIP 전용관, 콘텐츠-상품 연결, 재구매·교차판매 | 전환율, 객단가, 재구매율, 회원 전환율, 순매출, 채널 순이익 |
| 2 | 카카오(CRM·상담) | 기존 고객 재구매, VIP 상담, 신상품 선공개, 휴면 재활성화, 구매 후 관리 | 상담·구매 전환율, 발송 1건당 기여이익, 재구매율, 수신거부율 |
| 3 | 스마트스토어·네이버 | 검색수요 흡수, 신규 고객 획득, 가격·후기·배송 경쟁력 검증 | 노출, CTR, 구매 전환율, 광고비 차감 후 기여이익, 리뷰, 신규 고객 비율 |

- 모든 채널에 같은 상품·가격·콘텐츠를 복사하지 않는다. SKU별로 트래픽·수익·VIP·재고회수 등 역할을 부여한다.
- 네이버 광고는 기존 기록상 Premium Log Analysis 픽셀 미작동으로 전환 추적이 불가하므로 광고 집행을 재개하지 않는다. 추적 복구와 소규모 테스트 조건은 별도 검증한다.
- 채널별 수수료·광고비·배송비·반품비·상담/포장 인건비를 차감한 기여이익을 산출한다. 현재 실제 수치는 데이터 미연결이다.

## 5. 빠른 배송 운영 기준과 재고·포장·출고 프로세스

### 기준

- 목표 배송 SLA, 당일배송 가능지역, 택배사, 배송비, 마감시각은 **대표 결정 필요** 및 외부 검증 전 미확정이다.
- “빠른 배송”은 속도만 홍보하지 않고, 재고 실재·검수 완료·포장 완료·출고 스캔까지 추적 가능한 상태를 뜻한다.

### 프로세스

1. **주문 접수:** 채널 주문번호·SKU·고객 요청·결제 상태를 단일 주문 대장에 기록한다.
2. **재고 잠금:** 판매 가능 재고와 주문을 대조하고 중복 판매를 막는다.
3. **검수:** 브랜드/모델/사이즈/색상/상태/부속품/정품·통관 증빙을 확인하고 사진을 보관한다.
4. **포장:** 오염·훼손 방지 포장, 구성품 확인, 주문자·SKU 교차검수, 고가품 별도 포장 기준을 적용한다.
5. **출고:** 송장 등록, 출고 시각, 담당자, 포장 사진·검수 체크를 기록한다.
6. **배송 모니터링:** 미집하·지연·분실·파손을 예외 큐로 관리하고 고객에게 먼저 안내한다.
7. **반품·교환:** 회수 후 상태·구성품·훼손 여부를 검수하고 재판매/보류/A/S로 분류한다.

- 재고 정확도, 주문→출고 리드타임, 오출고, 파손, 반품 처리기간, 배송비 차감 후 기여이익을 D+7/D+14/D+30/D+90에 검토한다.
- 포장재 단가, 인력 소요, 택배 계약, 보험·분실 보상 범위는 **대표 결정 필요**.

## 6. 온라인 차별점: 정품 신뢰·실물 확인·상담·A/S

- **정품 신뢰:** 상품별 공급처·인보이스·통관 자료·검수 기록·구성품을 보유하고, 공개 가능한 범위와 제공 시점을 정의한다. 증빙이 불충분한 상품은 판매·추가 발주를 보류한다.
- **실물 확인:** 상세 사진·영상, 흠집/사용감 고지, 사이즈 실측, 소재·부속품 설명, 예약 쇼룸 확인을 제공한다. 사진과 실제 상태가 다르면 CS 기준에 따라 처리한다.
- **상담:** 카카오 상담과 자사몰 상품 페이지를 연결해 사이즈·착용감·코디·재고·배송·정품 증빙 질문을 주문 전 해결한다. 상담에서 발생한 주문은 채널별 기여를 잃지 않도록 추적한다.
- **A/S·수선·세탁:** 기존 자료의 순서대로 수작업 접수 → 제휴업체 품질 검증 → 건당 원가·판매가·클레임률 측정 → 월 처리량 확인 → 반복업무만 시스템화한다. 서비스별 수요·기여이익·업체 SLA 확인 전 본개발은 보류한다.
- 차별 서비스의 비용, 무상/유상 범위, 책임 한도, 처리기간은 **대표 결정 필요**이며 확정 전 과장된 보증 문구를 사용하지 않는다.

| 고객 | 상담 전환율, 구매 전환율, 재구매율, CRM 기여 순이익 | 카카오·쇼룸·콘텐츠 접점을 주문에 연결 | 대표 결정 필요 |
| 운영 | 주문→출고 시간, 오출고·파손·반품률 | 주문·검수·포장·출고 로그로 측정 | SLA·허용범위 대표 결정 필요 |

## 10. 오프라인 즉시 폐점 손실을 막는 전환 게이트

다음 전부를 확인하기 전 즉시 폐점·계약해지·대량 재고처분을 하지 않는다.

- [ ] 충성고객 온라인 이전율 50% 이상
- [ ] 4개 매장 고객 데이터 백업률 100%
- [ ] CRM 핵심 기능 검수 완료
- [ ] 매장별 매출·매출총이익·고정비 확인
- [ ] 통합 전후 12개월 손익 비교
- [ ] 이전비·원상복구비·보증금 회수 일정 확인
- [ ] 창고 겸 사무실 임차료·인건비·물류비 산출
- [ ] 당일배송 가능지역과 비용 검증
- [ ] 폐점에 따른 예상 매출이탈 계산
- [ ] 통합 투자금이 가용현금의 30% 이하
- [ ] 정품·통관·A/S 증빙과 온라인 CS·반품 SOP 검수 완료
- [ ] 다음 30일 현금 유입·유출에 폐점·이전 비용 반영

게이트 판정은 `D+7 초기 반응 → D+14 판매 가능성 → D+30 손익·재고회전 → D+90 재구매·장기 수익`으로 기록한다. 게이트 미충족이면 선택지는 **병행 유지 또는 축소·예약제**이며, 즉시 폐점은 선택하지 않는다.
