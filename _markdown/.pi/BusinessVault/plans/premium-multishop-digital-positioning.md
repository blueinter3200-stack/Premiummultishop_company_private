# Premium MultiShop 디지털 전환 포지셔닝

- 기준일: 2026-08-13
- 사업: Premium MultiShop
- 상태: 방향 확정 / 실행 설계 필요

## 1. 확정 슬로건

### 메인 슬로건

> **세계 공급망에서 지금 살 가치가 있는 상품을 찾아주는 쇼핑몰**

### 고객용 짧은 표현

> **지금 살 가치가 있는 상품만 찾아드립니다.**

### 내부 전략 문장

> Premium MultiShop은 상품을 많이 쌓아두는 쇼핑몰이 아니라, 세계 공급망의 가격·재고·정품·배송·수요 데이터를 비교해 고객에게 지금 구매할 가치가 있는 상품을 선별하고 제안하는 디지털 큐레이션 커머스다.

## 2. 포지셔닝 전환

| 기존 인식 | 전환 후 목표 인식 |
|---|---|
| 상품이 많은 명품 쇼핑몰 | 살 가치가 검증된 상품을 찾아주는 쇼핑몰 |
| 브랜드·카테고리 중심 진열 | 가격·재고·희소성·배송·정품 신뢰를 결합한 선별 |
| 판매자가 가진 재고 중심 | 세계 공급망에서 발견한 기회상품 중심 |
| 할인율 중심 구매 유도 | 구매 이유와 실질 가치 중심 구매 유도 |
| 상품 등록 후 광고 | 데이터 선별 → 콘텐츠 → 고객별 제안 |
| 단순 가격 비교 | 가격·배송·증빙·상담·사후관리의 종합 가치 비교 |

## 3. 고객에게 약속할 가치

Premium MultiShop의 ‘살 가치’는 단순히 싼 가격이 아니다.

1. **가격 가치**: 동일 SKU의 공급가·경쟁가를 비교해 합리적인 가격인지 확인
2. **상품 가치**: 현재 시즌·수요·활용도·희소성을 설명
3. **재고 가치**: 실제 구매 가능한 재고와 확인 시각을 표시
4. **시간 가치**: 국내재고·출고일·배송예정일을 명확히 제시
5. **신뢰 가치**: 정품·구매경로·통관·구성품·검수 범위를 설명
6. **서비스 가치**: 매장 상담·피팅·픽업·수선·세탁·관리 제공

## 4. ‘지금 살 가치’ 판정 엔진

상품은 아래 데이터가 충족될 때만 ‘추천’ 또는 ‘기회상품’으로 노출한다.

- 경쟁사 대비 실질 가격 경쟁력
- DDP 또는 확인된 총원가
- 공급처와 자사 재고의 신뢰도
- 정품·구매증빙·통관 자료
- 배송 리드타임과 반품 조건
- 최근 수요·조회·문의·판매 신호
- 할인 후 목표 기여이익
- 시즌성과 활용도
- 가격 하락·품절·반품 리스크

추천 배지 예시:

- **오늘의 가격 기회**
- **국내 즉시출고**
- **공급처 비교 완료**
- **소량 확보 상품**
- **매장 실물 확인 가능**
- **재입고 불확실**

‘최저가’, ‘공식’, ‘독점’, ‘100% 정품’ 등 법적·계약상 확인이 필요한 표현은 증빙과 검토 없이 사용하지 않는다.

## 5. 디지털 운영 구조

```text
세계 공급처
  ↓ 가격·재고·배송·정품·DDP 데이터 수집
Premium MultiShop 상품 선별 엔진
  ↓ 살 가치 점수·최저 판매가·공급 안정성
Cafe24 자사몰
  ↓ 상품 페이지·가격 기회·콘텐츠·상담
Meta·검색·카카오 CRM
  ↓ 고객별 관심·가격·재입고·선공개 메시지
구매·매장 상담·픽업·사후관리
  ↓ 판매속도·기여이익·재구매 데이터
다음 바잉·공급처 평가
```

## 6. 콘텐츠 방향

상품을 소개하는 콘텐츠가 아니라 ‘왜 지금 살 가치가 있는지’를 설명한다.

- 경쟁가 대비 현재 가격이 합리적인 이유
- 같은 브랜드 안에서 이 모델을 선택할 이유
- 소재·핏·사이즈·활용도
- 현재 확보 수량과 재입고 가능성
- 국내 출고와 해외 주문의 차이
- 정품·구매증빙·통관 처리 방식
- 매장 실물 확인·피팅·픽업
- 구매 후 수선·세탁·보관 방법

## 7. 실행 순서

### Phase 1 — 정의

- 슬로건과 ‘살 가치’ 판정 기준 확정
- 가격·재고·정품·배송·수요·마진 데이터 필드 확정
- 추천 배지와 금지 표현 확정

### Phase 2 — 데이터 MVP

- 공급처 1곳
- 상품 20~50개
- 읽기 전용 가격·재고 연동
- 사람이 승인하는 상품 선별표

### Phase 3 — 고객 반응 검증

- 5개 이하 SKU 공개
- 상품별 ‘왜 지금 살 가치가 있는가’ 콘텐츠 제작
- 카카오·Meta·자사몰·매장 상담을 고객군별 테스트
- D+7/D+14/D+30 기여이익과 재고회전 확인

### Phase 4 — 자동화 확대

- 공급처 추가
- 가격·재고 비교 자동화
- 고객 관심 기반 추천
- 구매·재구매·공급처 성과 데이터 연결

## 8. 핵심 KPI

- 추천 상품 클릭률·상담률·장바구니율·구매전환율
- 추천상품의 광고비 포함 기여이익
- 가격·재고 데이터 최신성
- 품절 오노출률·가격 오류율
- 추천상품 재고회전일·현금회수기간
- 고객별 재구매율·카카오 수신거부율
- 공급처별 가격 경쟁력·배송 성공률·반품률

## 9. 전략적 판단

슬로건만 바꾸고 상품을 대량 등록하면 디지털 전환이 아니다. 고객이 실제로 체감하려면 다음 4가지가 연결되어야 한다.

1. 세계 공급망을 비교하는 데이터
2. 사람이 승인하는 정품·가격·배송 검증
3. ‘살 가치’를 설명하는 콘텐츠
4. 고객 행동과 실제 이익을 측정하는 CRM·손익 시스템

따라서 Premium MultiShop의 디지털 전환은 **상품 수 확대 프로젝트가 아니라 상품 선별·추천·판매·학습 시스템 구축 프로젝트**로 관리한다.
