# PMS 계단형 상품·고객·수익 구조 v1.0

- 기준일: 2026-08-15
- 사업: Premium MultiShop
- 상태: 전략 구조 확정 / 실제 가격대·전환율·LTV는 데이터 검증 필요

## 1. 한 줄 결론

PMS는 모든 상품을 같은 방식으로 팔지 않고, 무료 콘텐츠로 신뢰를 쌓은 뒤 진입상품·주력상품·프리미엄·VIP로 고객과 현금을 단계적으로 이동시키는 **Revenue Ladder**를 운영한다.

```text
무료 콘텐츠
→ 회원·카카오 친구
→ 첫 구매
→ 주력 상품
→ 고가 명품
→ 개인 소싱·예약판매·B2B
```

## 2. 계단별 역할

### LEVEL 0 — Free Trust & Demand

목적: 구매가 아닌 관심·신뢰·회원 식별.

Premium MultiShop 주제:

- 이번 주 해외 명품 가격차 TOP 10
- 유럽 현지 신상품 동향
- 이번 주 실제 한정 수량
- 명품 정품 확인법
- 국내 vs 유럽 가격 비교
- 해외 셀럽 착용상품의 브랜드·모델 분석
- 시즌별 사이즈·소재·관리법
- 병행수입·해외 주문형·국내재고 차이
- 구매 전 통관·반품·A/S 체크리스트

K-Beauty 해외 인기상품 TOP 10은 BELLOON 콘텐츠로 분리한다. Premium MultiShop과 고객·상품·CRM·수익 데이터를 섞지 않는다.

목표:

```text
Instagram / YouTube / Naver
→ 콘텐츠 랜딩
→ Kakao 친구·PMS 회원
→ 관심 브랜드·가격대·사이즈 수집
```

관리 KPI:

- 유효 콘텐츠 조회
- 저장·공유
- 프로필·랜딩 클릭
- 카카오 친구 추가
- 회원가입
- 선호 브랜드·가격대 입력률
- 콘텐츠 귀속 상담
- 콘텐츠 귀속 CM2

무료 콘텐츠는 조회수보다 **식별 가능한 구매의도 데이터**를 남겨야 한다.

### LEVEL 1 — Entry Product

가격 가설: 30,000~150,000원.

가능 카테고리:

- 액세서리
- 소형 패션상품
- 선글라스·소품
- 진입 장벽이 낮은 특가상품
- 검증된 소형 명품 관련 상품

화장품은 Premium MultiShop에 넣지 않고 BELLOON에서 별도 검토한다.

목적:

- 첫 결제
- 결제·배송·반품 신뢰 형성
- 고객 사이즈·브랜드·가격대 데이터 확보
- 다음 상품 추천의 근거 생성

판정 기준:

- 첫 주문 CM1 양수
- 반품·클레임 관리 가능
- 진품·구성품·배송 증거 확보
- 재구매·교차판매 후보 존재
- 무리한 할인으로 고객을 모으지 않음

### LEVEL 2 — Main Product

가격 가설: 300,000~1,500,000원.

예시:

- 스니커즈
- 선글라스
- 지갑
- 일부 가방
- 핵심 패션상품

역할:

- PMS의 본격적인 이익원
- 고객별 브랜드·가격대·사이즈 학습
- READY·RARE 상품의 주력 판매
- 콘텐츠·CRM·검색 유입의 최종 회수

핵심 KPI:

- 주문당 CM1·CM2
- 장바구니율·CVR
- 재고회전일
- 배송약속 준수율
- 반품·정품·구성품 문제율
- 첫 구매→두 번째 구매 전환율

### LEVEL 3 — Premium

가격 가설: 1,500,000~5,000,000원.

예시:

- Chanel
- Goyard
- Hermès
- 고가 가방·시계·희소 패션

역할:

- 객단가 확대
- 신뢰·상담·검수·사후관리의 수익화
- VIP 후보 발굴
- 예약 쇼룸·실물 상담 연결

운영 조건:

- SKU 상품여권 필수
- 실물·구성품·검수 증거 필수
- 판매자 단일 책임창구
- 배송·반품·정품 분쟁 프로토콜
- 고액 환불·보상 승인
- 재고·현금 노출액 제한

고가 상품은 매출보다 **최대손실·현금회수·신뢰비용**을 먼저 본다.

### LEVEL 4 — VIP / Concierge

대상:

- VIP 개인 소싱
- 예약판매
- 해외 Pre-order
- 한정상품
- 기업·스타일리스트·리셀러 B2B
- 반복 구매 고객

역할:

- 높은 객단가
- 높은 실제 LTV
- 선주문·예약으로 재고위험 제한
- 고객별 취향·사이즈·브랜드 데이터 축적
- 개인 상담·검수·A/S를 서비스 프리미엄으로 수익화

필수 통제:

- 선입금·예약금·환불 조건
- 조달 실패·지연 조건
- 정품·통관·수입자 책임
- B2B 재판매 권한·계약
- 개인 고객과 사업자 고객 구분
- 주문별 최대 노출액

## 3. 고객 이동 규칙

고객을 매출액만으로 승급시키지 않는다.

### L0 → L1

- 콘텐츠 또는 상담에서 구매의도 확인
- 수신동의 확인
- 첫 구매 상품의 재고·배송·반품 조건 검증
- Entry 상품 CM1 양수

### L1 → L2

- 첫 주문 수령 완료
- 반품·클레임 없음 또는 해결 완료
- 브랜드·사이즈·가격대 데이터 확보
- 주력상품 추천의 경제성 확인

### L2 → L3

- 반복 구매 또는 고가 상품 관심
- 상담·실물 확인 수요
- 신뢰·검수·A/S 비용을 포함한 CM1 양수
- 고액 상품 투자·보상 한도 확인

### L3 → L4

- 실제 고가 구매·재구매
- 예약·개인 소싱 요청
- 선호 브랜드·사이즈·예산 확인
- 주문별 최대손실과 조달 조건 합의

승급이 아니라 하락 신호도 기록한다.

- 장기 미구매
- 할인만 반복 요구
- 반품·클레임 반복
- 상담비용 대비 기여이익 음수
- 동의 철회

## 4. 계단형 수익 구조

```text
L0 무료 콘텐츠 비용
→ L1 첫 구매에서 신뢰·데이터 회수
→ L2 주력 상품에서 안정적 CM1·CM2 회수
→ L3 고가 상품에서 상담·신뢰 프리미엄 회수
→ L4 예약·소싱·B2B에서 높은 LTV와 선주문 현금 회수
```

무료 콘텐츠가 유료 광고처럼 작동하려면 다음을 측정한다.

```text
콘텐츠 CM2
= 콘텐츠 귀속 주문 CM1
- 콘텐츠 제작비
- 발송·CRM 비용
- 광고·제휴비
```

L0 콘텐츠는 직접 구매가 없어도 괜찮지만, 회원·상담·첫 구매·향후 실제 LTV로 연결되는지 확인해야 한다.

## 8. 핵심 KPI

### 계단별

- L0: 유효 도달·저장·회원·카카오 전환
- L1: 첫 구매율·CM1·반품률·두 번째 구매율
- L2: CVR·CM1·CM2·재고회전·재구매
- L3: 상담→결제·객단가·고액 반품·서비스 비용
- L4: 예약 전환·예약금 회수·실제 LTV·주문별 최대손실

### 회사 전체

- 레벨별 고객 수
- 레벨 이동률
- 레벨별 실제 LTV
- 레벨별 CAC
- 레벨별 CM1·CM2·CM3
- 고객 이동 소요기간
- 재구매 간격
- 콘텐츠 귀속 매출·기여이익
- 계단별 현금회수기간
- 장기재고 금액

## 10. 첫 30일 실행

1. L0 콘텐츠 5개 주제 선정
2. READY 3개·RARE 2개 상품페이지 전환 테스트
3. L1 진입상품 후보 3~5개 원가·반품·재고 검증
4. L2 주력상품 고객 세그먼트·상담 CTA 적용
5. Global Trend & Content Scout는 공개 데이터 수동 수집으로 시작
6. 콘텐츠→회원→상담→주문 ID 연결
7. D+7·D+14·D+30 CM1·CM2·재고·재구매 측정

확대 조건:

- 콘텐츠가 식별 가능한 회원·상담·주문으로 연결
- L1이 CM1 양수
- L2가 재고·현금 하드스톱 통과
- L3·L4의 고액 책임·보상 조건 문서화
- 콘텐츠 Agent의 원본·권리·증거 상태 관리
