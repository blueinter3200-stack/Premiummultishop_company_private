# 홍콩 보세창고·해외 매입·구매대행 모델 구조 검토

- 기준일: 2026-08-15
- 사업: Premium MultiShop 전용
- 상태: 사업모델 설계 검토 / 관세사·법률·세무 검토 전 확정 금지

## 1. 대표님 구상 구조

```text
유럽·해외 공급처 경쟁력 가격 매입
→ 홍콩 보세창고 랜딩·보관
→ 한국 고객 주문
→ 구매대행 판매
→ 150달러 이하 고객 명의 통관 검토
→ 소비자 배송
```

이 구조는 해외 재고를 국내에 미리 수입하지 않고, 주문 후 고객에게 배송해 국내 보관·재고·고정비를 낮추려는 모델이다.

## 2. 핵심 판정

이 모델은 원가·재고 측면에서 사업적 가능성이 있지만, **150달러 이하 고객 명의 통관이 자동으로 허용되는 구조는 아니다.**

최우선 확인사항:

1. 홍콩 보세창고 상품의 법적·경제적 소유자
2. 해외 공급처와의 매입 계약 당사자
3. 고객 주문 시 실제 판매자·구매대행자
4. 결제금액의 구성: 상품대금·운임·수수료
5. 고객이 특정 상품을 주문한 후 구매하는지
6. 주문 전 이미 사업자가 재고를 보유·통제하는지
7. 송장 발행자·수출자·수입자·통관명의자
8. 반품·환불·정품분쟁의 책임자
9. 같은 SKU를 반복적으로 다수 고객에게 판매하는지
10. 개인통관고유부호 수집·전달·보관 방식

사업자가 상품을 선매입하고, 홍콩 보세창고에 자기 재고로 보관한 뒤, 여러 고객에게 반복 판매한다면 `구매대행`이라는 표기만으로 실제 거래성격이 바뀌지 않을 수 있다. 재판매용 사업재고를 고객 개인 자가사용 직구로 처리할 수 있는지는 관세사·법률 검토가 필요하다.

## 3. 세 가지 거래모델 분리

### Model A. 국내재고 병행수입 판매

```text
Premium MultiShop 매입
→ 국내 사업자 수입·통관
→ 검수·보관
→ 소비자 판매
```

- 판매자: Premium MultiShop
- 재고: Premium MultiShop
- 수입자: 사업자
- 장점: 고객 경험·배송·반품·검수 통제
- 단점: 관세·부가세·재고·현금 부담
- 적합 상품: 핵심 SKU·VIP·즉시배송·고가상품

### Model B. 진정한 구매대행

```text
고객의 특정 상품 구매 요청
→ Premium MultiShop이 구매대행
→ 해외 판매자에게 고객 주문을 전달
→ 고객이 최종 수취인·수입자 역할
```

- 구매대행 계약·수수료·배송·통관 책임을 명확히 표시
- 상품대금과 구매대행 수수료를 구분
- 고객 주문 전 공급처·가격·배송·반품 조건 고지
- 구매대행자가 사실상 상품을 보유·통제하는 구조인지 검토
- 고객의 청약철회·환불·분쟁 책임을 별도 검토

### Model C. 홍콩 보세창고 기반 해외재고 판매/DDP

```text
사업자 또는 해외 공급처 재고
→ 홍콩 보세창고
→ 고객 주문
→ 한국 수입통관
→ DDP 또는 지정 수입자 배송
```

- 홍콩 보세창고는 홍콩 내 관세·세금과 한국 수입통관을 자동으로 해결하지 않음
- 한국 수입자·HS코드·신고가격·관세·부가세·통관료·반품 책임을 별도 확정
- 고객 명의 통관을 쓰는 경우에도 진정한 구매대행인지 검토
- DDP는 계약서·견적서·운송조건으로 검증

## 4. 150달러 기준의 적용 한계

관세청 공개 안내의 150달러 기준은 **자가사용으로 인정되는 소액 해외직구 물품**에 관한 기준이다.

따라서 다음 사실만으로 면세를 확정하지 않는다.

- 상품가격이 150달러 이하
- 고객 개인통관고유부호를 받음
- 홍콩에서 소비자에게 직접 배송
- 쇼핑몰에 구매대행이라고 표시

다음 요소가 결합되면 사업자 재판매로 볼 위험을 관세사·법률 전문가와 검토해야 한다.

- 사업자가 상품을 선매입
- 사업자가 재고를 소유·통제
- 동일 SKU를 반복 판매
- 사업자가 가격·재고·공급처를 결정
- 고객은 주문·결제만 하고 상품 선정에 관여하지 않음
- 사업자가 판매 후 환불·정품·A/S를 책임짐
- 홍콩 보세창고가 사업자 전용 재고 거점으로 사용됨

## 5. 홍콩 보세창고 필수 확인서류

- 보세창고 계약서
- 보세구역의 법적 지위와 허용 업무
- 상품 소유권과 재고 소유자
- 입고·출고·재포장·검수 가능 범위
- 창고 내 상품별 SKU·수량·시리얼 관리
- 보험·분실·파손 책임
- 홍콩에서 한국으로 수출하는 주체
- 상업송장 발행 주체
- 원산지·HS코드 자료
- 한국 수입자·통관명의자
- DDP·운송·통관 계약
- 한국 반품 시 반입·환급·재수출 절차
- 정품분쟁·공급처 환불 조건

## 6. 고객-facing 상품 유형

| 유형 | 고객 안내 | 배송 | 판매 전제 |
|---|---|---|---|
| A 국내 즉시출고 | 국내 실재고·출고일 | 국내배송 | 사업자 수입·판매·검수 |
| B 해외 주문형 | 해외재고·예상일·통관책임 | 해외직배송/DDP | 공급처·DDP·반품 검증 |
| C 상담 구매대행 | 구매대행 수수료·계약·책임 | 고객 주문 후 해외구매 | 진정한 대행 구조·법률 검토 |
| D 검증 후보 | 판매 불가 | - | 증빙·가격·재고 미확인 |

상품 페이지에서 A/B/C를 혼용하지 않는다.

## 7. 손익 계산

### 구매대행 주문

```text
고객이 지급한 총액
- 해외 상품대금
- 해외 현지 운송비
- 국제운송비
- 결제·환전·송금 수수료
- 구매대행 운영비
- 통관·대납·DDP 비용
- CS·반품충당금
- 플랫폼·결제 수수료
- 광고·할인비
= 주문당 기여이익
```

### 홍콩 보세창고 비용 포함

```text
주문당 기여이익
- 홍콩 입고 운송비 배부
- 보세창고 보관료
- 입출고·피킹·재포장비
- 검수·촬영비
- 보험·분실충당금
- 재고자금 비용
= 조정 기여이익
```

## 8. 추천 테스트 설계

### 테스트 A: 해외 직배송/구매대행

- 3~5 SKU
- SKU당 1~2건
- 고객 주문별 거래구조 기록
- 홍콩 보세창고 출고부터 고객 수령까지 추적
- 고객 통관·배송·반품 책임을 사전 고지

### 테스트 B: 국내재고

- 동일 또는 유사 SKU 1~2개 선입고
- 국내 즉시배송·반품·상담 전환 비교
- 국내재고 자금·보관·장기재고 비용 계산

### D+14 비교

- 문의→결제 전환율
- 평균 배송일
- 배송 약속 준수율
- 취소율
- 반품률
- 고객 불만
- 상담 소요시간
- 주문당 기여이익

### D+30 비교

- 실제 환불 완료기간
- 공급처 환불 회수기간
- 현금회수기간
- 정품·구성품 문제
- 재구매 의향
- 최대 손실

## 9. 현재 권고

대표님이 구상한 홍콩 보세창고 기반 모델은 다음처럼 수정해 테스트하는 것이 안전하다.

1. `150달러 면세`를 핵심 홍보문구로 사용하지 않음
2. 구매대행·해외 직배송·사업자 수입판매를 약관·상품페이지·정산에서 분리
3. 홍콩 보세창고의 재고 소유·출고·통관 책임을 서류로 확인
4. 사업자 선매입 재고를 고객 개인 자가사용 직구로 단순 처리하지 않음
5. 관세사·전자상거래 전문 변호사에게 거래흐름 검토 의뢰
6. 3~5 SKU만 실제 주문으로 테스트
7. 국내재고 상품과 해외 주문형 상품의 전환·반품·기여이익 비교
8. 법적 구조가 확정되기 전 대량 광고·대량 등록·대량 발주 금지

## 최종 판정

- **사업적 가능성:** 있음
- **150달러 기준을 이용한 가격경쟁:** 구조 확정 전 보류
- **홍콩 보세창고:** 보세·소유권·통관·반품 서류 확인 후 제한 테스트
- **구매대행:** 진정한 대행 구조인지 전문가 검토 필요
- **국내 핵심재고:** 신뢰·배송·상담 중심 SKU에 유지
- **3PL:** 표준상품에 제한 도입
- **대량 확대:** D+30 손익·통관·반품 검증 후 결정
