# Premium MultiShop 해외 리테일 구매·국내 리셀 수익성 재검토

- 기준일: 2026-08-16
- 상태: **기존 제안 구조는 진입 금지 / 수정 모델만 조건부 검토**
- 자료 성격: 대표님이 공유한 일부 해외 플랫폼 정책은 작년 준비자료로 분류하며 현재 정책으로 확정하지 않음

## 1. 최종 판정

### 진입 금지

다음 구조는 PMS의 기본 수익모델로 사용하지 않는다.

```text
해외 소비자용 플랫폼 구매
→ 반품 가능성을 이용해 재고 리스크 회피
→ 관부가세 환급을 수익으로 계산
→ 카드 캐시백을 이익에 추가
→ 국내에서 반복 재판매
```

이유:

- 반품·관세·부가세 환급은 이익이 아니라 거래 취소·세금 정산일 수 있음
- 환급 가능 여부·범위·신청주체·서류·기한이 거래유형마다 다름
- 소비자용 구매계정·프로모션·카드 혜택을 사업 재판매에 반복 사용하면 약관·세무·계정 제재 위험
- 개인통관고유부호를 사업 재고의 우회 수단으로 사용할 수 없음
- 해외 플랫폼의 판매권·재판매 권한이 확인되지 않음
- 해외 소비자 소매가격과 국내 사업자의 완전원가를 단순 비교함
- 반품이 허용된다고 해서 재판매용 선매입이 허용되는 것은 아님

### 조건부 검토

다음 구조만 소량 테스트할 수 있다.

```text
사업자 거래·수출입·공급·정품 서류 확인
→ 실제 수입자·납세자·소유권 확인
→ 국내 판매 완전원가 계산
→ 국내 판매가격·수요 사전 확인
→ 대표 승인
→ 3~5 SKU·SKU당 1~2개 테스트
→ CM1·CM2·현금회수·반품 실제 측정
```

## 2. 제시된 3억 원 계산의 오류

대표님이 공유한 예시는 계산 자체는 다음과 같다.

```text
구매액 300,000,000원
국내 리셀 마진 20%       = 60,000,000원
카드 캐시백 1.5%         = 4,500,000원
관부가세 25%             = 75,000,000원
합계                     = 139,500,000원
```

그러나 이 139,500,000원을 수익으로 인정할 수 없다.

### 오류 1 — 해외 구매가와 국내 판매가 차이는 마진이 아님

국내 판매가에서 다음을 차감해야 한다.

- 국제운송
- 관세·수입부가세·통관료
- 환율·환전·해외결제 비용
- 국내 배송·포장·검수
- 플랫폼·결제 수수료
- 할인·쿠폰
- 광고·콘텐츠·CRM
- 반품·취소·불량·정품분쟁 충당금
- A/S·수선·보관
- 재고 금융비용
- 세무·회계 비용

### 오류 2 — 반품 시 관부가세 환급은 수익이 아님

반품으로 거래가 취소되면서 납부세액 일부가 환급되는 것과, 판매가 발생해 수익을 얻는 것은 전혀 다르다.

```text
세금 환급
≠ 매출
≠ 영업이익
≠ 재판매 마진
```

관세청은 해외직구 반품·관세환급 절차와 증빙을 별도로 안내하고 있다. 환급은 자동·일률적으로 25~35%가 발생한다고 계산할 수 없다.

### 오류 3 — 카드 캐시백은 확정 수익이 아님

카드 혜택은 다음 확인 전 수익으로 반영하지 않는다.

- 사업용 카드 여부
- 해외 이용수수료
- 캐시백 제외 업종·가맹점
- 월별·건별 한도
- 프로모션 기간
- 반복 구매·재판매 거래 제한
- 환불 시 캐시백 회수
- 세무상 처리

### 오류 4 — 3억 원 매입으로 월 1억 원 수익은 검증 불가

3억 원은 매입 투자액일 뿐 월 판매량·판매기간·재고회전·현금회수를 의미하지 않는다.

월 1억 원 이익을 주장하려면 최소한 다음이 필요하다.

- SKU별 판매수량
- SKU별 국내 실현판매가
- SKU별 완전원가
- 판매기간·재고회전
- 반품·취소율
- 채널별 수수료·정산지연
- 광고·CRM 비용
- 실제 현금 회수
- 세금·회계 처리

## 3. 수익이 발생할 수 있는 올바른 구조

### 수익원

```text
국내 실현판매가
- 해외 매입·사업자 공급가
- 국제운송·통관·관세·부가세
- 국내 검수·포장·배송
- 플랫폼·결제 수수료
- 할인·광고·CRM
- 반품·분쟁·A/S 충당금
= 실현 CM1/CM2
```

추가적인 서비스 가치:

- 국내 즉시 출고
- 국내 반품 주소
- 상품 실물 검수
- 한국어 상담
- 통관·배송 책임 창구
- CARE 사후관리
- 예약 쇼룸·실물 확인

이 서비스가 실제로 국내 고객의 지불의사를 높이는지 확인해야 한다. `국내 소비자는 해외보다 15~30% 더 지불한다`는 일반 가정은 근거 확보 전 사용하지 않는다.

## 4. 플랫폼 활용 원칙

### 사용 가능성이 있는 경우

- 사업자 판매·공급계약이 존재
- 재판매 권한 확인
- 상업송장·수출입 서류 발급 가능
- 수입자·납세자 명확
- 정품·브랜드·A/S 책임 확인
- 국내 판매용 원가 산출 가능
- 반품·환불이 사업거래 조건에 맞음

### 소비자용 소매 플랫폼의 제한

Net-A-Porter·Mytheresa·Farfetch·SSENSE·Amazon Global 등은 과거 정책상 구매·반품 편의성이 높아 보일 수 있으나, 대표님이 공유한 자료는 작년 자료이며 현재 정책으로 확정하지 않는다.

특히 다음은 확인 전 사용하지 않는다.

- 무료 반품을 재고보험으로 간주
- DDP를 사업자 재판매의 세금 해결책으로 간주
- 소비자용 할인·신규고객 쿠폰의 반복 사용
- 카드 캐시백의 무제한 수익화
- 개인통관고유부호를 사업 재고에 활용
- 소비자 약관상 반품권을 도매·재판매 권한으로 해석

## 5. 상품 선정 기준

리셀 후보는 브랜드명이 아니라 SKU별로 평가한다.

필수 입력:

- SKU·모델·사이즈·색상
- 해외 공급가격
- 판매자·거래유형
- 국내 판매 가능성
- 국내 실현가격
- 환율·운송·관세·부가세·통관료
- 포장·검수·배송
- 채널 수수료
- 반품·A/S·분쟁 충당금
- 공급·정품·재판매 증거
- 예상 판매기간
- 현금 회수기간

우선 검토 상품:

- 국내 READY로 전환했을 때 배송·실물확인 가치가 명확한 상품
- 사이즈·반품 위험이 낮은 액세서리·소형 상품
- 국내 공급 부족과 실제 검색·문의가 확인된 상품
- 구성품·정품·상태 증거 확보가 쉬운 상품
- 소량 구매 후 빠른 회수가 가능한 상품

초기 보류 상품:

- 사이즈 반품률이 높은 의류·신발
- 정품 감정이 어려운 상품
- 가격 변동이 큰 한정판
- 보증·전압·언어·병행수입 이슈가 있는 전자제품
- 화장품·식품 등 BELLOON·별도 규제 검토가 필요한 상품
- 중고·리퍼브·전시품 상태가 불명확한 상품

## 6. PMS 테스트 규칙

- 3~5 SKU
- SKU당 1~2개
- 신규 투자 상한 300만 원 내부 보수기준
- 14일 초기 반응
- 30일 손익·현금·재고회전
- 모든 상품 READY/RARE·책임·반품 조건 표시
- 대표 승인 전 발주 확대 금지

`margin_check.py`에서 필수 데이터·법적 안전·정품·권리·통관이 모두 확인되기 전에는 발주가 아니라 검증 보류다.
