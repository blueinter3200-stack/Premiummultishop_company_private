# Premium MultiShop 온라인 전환·고정비 구조 피보팅 가설

- 기준일: 2026-08-15
- 공개 확인 URL: https://premiummultishop.com/timesale
- 사업: Premium MultiShop 전용
- 상태: 대표님 운영 가설 / 손익·법무·통관 검증 전 확정 금지

## 1. 대표님이 제시한 전환 가설

오프라인 매장은 임대료·관리비·인건비 등 고정비가 크고 입점 고객이 감소하는 반면, 실제 주문은 카카오톡 상담과 온라인에서 주로 발생한다. 따라서 고객서비스를 유지하면서 매장 중심 구조를 온라인 중심으로 전환하고, 고정비를 축소하는 방안을 검토한다.

검토 후보:

- 최소 인원 온라인 운영
- 카카오 상담·주문 중심 고객서비스
- 선택·집중형 SKU 발굴
- 해외 거래처 직접 발굴
- 해외 직배송·개인 배송
- 홍콩 보세창고 활용
- **150달러 기준은 자가사용 해외직구에 적용되는 공개 통관 기준일 뿐, 사업자의 재판매 상품을 고객 개인 직구처럼 처리하는 가격전략으로 확정하지 않음**
- 일정 금액 초과 상품의 해외 공급처 DDP 배송
- 네이버 판매가격 노출과 채널 경쟁력
- 기존 매장 재고의 3PL 보관·판매
- 창고형 사무실·예약 쇼룸 통합

## 2. 공개 사이트 1차 확인

- Cafe24 기반 쇼핑몰
- `/timesale` 페이지에서 상품 상세 링크 약 144개 수준 확인(중복 링크 포함 HTML 기준)
- 럭셔리·컨템포러리·스포츠·신상·세일·라스트 피스 등 폭넓은 상품군 노출
- 현재는 고객이 선택할 기준보다 SKU 폭과 세일 노출이 먼저 보일 가능성 있음
- 본 공개 확인만으로 실제 재고·판매량·마진·주문 출처·카카오 전환은 확인 불가

## 3. 핵심 전략 방향

```text
오프라인 매장 중심
→ 온라인·상담·데이터 중심
→ 창고/검수/촬영/출고/예약 쇼룸 거점
→ 검증된 SKU·고객군·공급처만 확대
```

목표는 매장 폐점 자체가 아니라 다음을 개선하는 것이다.

- 고정비/주문 비율
- 고객 응답·상담 품질
- 실제 재고 정확도
- 주문·출고 속도
- 상품별 기여이익
- 재구매·교차판매
- 현금회수기간

## 4. 운영 형태 비교 가설

| 안 | 장점 | 위험 | 현재 판정 |
|---|---|---|---|
| 기존 매장 유지 | 실물 신뢰·상담·검수 | 고정비·방문객 감소 | 즉시 확대 보류 |
| 온라인+기존 매장 병행 | 전환 리스크 낮음 | 고정비 지속 | 단기 기준선 수집 |
| 창고형 사무실+예약 쇼룸 | 고정비 절감·물류/콘텐츠 통합 | 상권·고객접점·보안 재설계 | 조건부 유력 |
| 3PL 중심 | 고정비·출고 업무 절감 | 정품 검수·촬영·A/S·브랜드 경험 통제 약화 | SKU·주문량 확인 후 테스트 |
| 해외 직배송 | 재고·자금 부담 축소 | 배송·통관·반품·진위분쟁·고객경험 | 상품군별 제한 테스트 |
| 홍콩 보세창고 | 공급망·가격 가능성 | 보세·통관·실물검수·운영비·반품 확인 필요 | 공급처·통관 검증 전 보류 |

## 5. 중요한 법·손익 검증

- 특정 금액 이하 면세 여부는 물품가격만 보지 않고 적용 기준·운임·보험·품목·개인사용·분할배송·수입자 책임을 공식 기준으로 확인한다.
- 소비자에게 개인 해외배송 구조를 안내할 때 판매자·수입자·통관·관부가세·반품비·정품·A/S 책임을 명확히 표시한다.
- DDP는 배송비 포함 문구가 아니라 관세·부가세·통관료·추징·반품 책임까지 서면 확인한다.
- 네이버 판매가격 노출만으로 경쟁우위가 생기는지 실제 최종 결제가격·배송일·정품 신뢰·반품조건·플랫폼 수수료와 비교한다.
- 3PL·홍콩 보세창고·해외 직배송은 SKU별 완전원가와 주문당 운영비를 계산하기 전 확대하지 않는다.

## 6. 우선 검증 순서

1. 최근 12개월 매장별 고정비·매출·순이익·재고·주문 출처 분리
2. Cafe24·카카오·매장·네이버 주문의 실제 기여이익 비교
3. 상위 50개 SKU의 판매속도·마진·반품·문의·재구매 확인
4. 3PL 비용과 창고형 사무실 비용 비교
5. 국내 즉시출고·해외 직배송·DDP의 SKU별 완전원가 비교
6. 기존 재고 3~5개 SKU의 14/30일 회수 테스트
7. 매장 축소·예약 쇼룸·창고 통합의 D+90 게이트 판정

## 7. 현재 의사결정

- 즉시 전 매장 폐점: 보류
- 신규 대량 사입: 보류
- 해외 직배송·홍콩 보세창고 대규모 도입: 보류
- 온라인·카카오 상담·고정비 구조 기준선 수집: 실행
- 상위 SKU·기존 재고·3PL·창고형 사무실 소량 비교: 실행
- 고객서비스를 줄이는 전환: 금지
