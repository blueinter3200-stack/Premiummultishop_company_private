# 프리미엄멀티샵 — 바잉 채점 규칙 (Consilience AI 토론 수렴 엔진)

*확정일: 2026-07-21 · 버전: v1.1 (대표님 승인 — 마진 가중 상향) · 관리: 대표님 / 통제 에이전트(Claude)*
*목적: 4-AI(Claude·GPT·Gemini·Grok) 심층토론이 "의견 4개"에 그치지 않고 하나의 SKU/브랜드 랭킹으로 수렴하도록 만드는 공용 채점 규칙.*
*연계: `02_AI에이전트_운영규칙`(하드스탑·출력포맷) / `01_사업개요_KPI`(순마진율 12% 최우선) / `10_브랜드x소싱처_수요조건_매트릭스`(입력 후보군)*

## 0. 4-AI 역할 배분 (바잉용 재정의)

| AI | 담당 단계 | 산출물 |
| --- | --- | --- |
| **Claude** | 통제 에이전트 + 재무판단 | 마진 역산, 하드스탑 게이트 검사, 최종 종합·보고 |
| **ChatGPT(GPT)** | 정량 채점 + 콘텐츠 | SKU 스코어표, 리스팅/상세페이지 카피 |
| **Gemini** | 멀티모달 + 구글 생태계 | 상품 이미지·트렌드 비주얼 분석, 구글쇼핑·트렌드 수요신호 |
| **Grok** | 실시간 트렌드 + 반론 | X 급상승 아이템, 병행수입 상표·통관 리스크 공격 |

운영 방식: **오케스트레이션형** — Cowork 세션에서 Claude가 통제 에이전트로 서브에이전트에 각 역할을 부여해 다관점 토론 + 상호검증(adversarial)을 1세션에 실행.

## 1. 채점 2단 구조

### 1단계. 게이트 (하나라도 걸리면 점수 계산 없이 자동 처리)

| 게이트 | 기준 | 결과 |
| --- | --- | --- |
| 순마진율 | 관부세·수수료·환율 차감 후 12% 미만 | ❌ 탈락 |
| 법적 안전도 | 정품 인보이스·통관·상표·AS 중 하나라도 불명확 (4/5 미만) | ❌ 탈락 |
| 리드타임 | 45일 초과 | ❌ 탈락 |
| 재고회전 예상 | 90일 초과 | ❌ 탈락 |
| 데이터 신뢰도 | 0.70 미만 | ⏸ 보류(재검증) |
| 단일 투자금 | 가용현금(2억)의 30% = 6,000만 초과 | 🔺 대표 승인 게이트 |

### 2단계. 가중점수 (게이트 통과분만 · 각 축 0~5점 → ×가중치 → 100점 환산)

**가중치 v1.1 (2026-07-21 확정):**

| 평가축 | 가중치 | 5점 | 3점 | 0~2점 |
| --- | --- | --- | --- | --- |
| **예상 순마진율** | **40%** | ≥25% | 15~20% | 12~15%(2점) |
| **한국 수요신호** | **20%** | HOT + 최신확인 | STEADY | DECLINING(1)·NOT POPULAR(0) |
| **법적 안전도** | **15%** | 4요소 전부 명확 | 일부 확인 | (4 미만은 게이트 탈락) |
| **리드타임·재고회전** | **15%** | ≤30일 & 드롭십 가능 | ≤45일 사입 | — |
| **소싱 조건·파트너** | **10%** | 최상조건 + 복수처 | 코드보유 단일 | 미접촉·단독폐쇄위험(1) |

> 환산식: `최종점수 = (Σ 축점수×가중치) / 5 × 100`. 만점 = 5점 전 축.

## 2. 최종 등급 → 액션 (운영규칙 출력 문구 연동)

| 점수 | 등급 | 액션 |
| --- | --- | --- |
| 85~100 | **즉시 실행** | 사입/발주 준비 (투자금 게이트 확인) |
| 70~84 | **제한 테스트** | 드롭십 무재고 파일럿 → 검증분만 사입 |
| 50~69 | **보류** | 데이터 보강 후 재채점 |
| <50 / 게이트 탈락 | **중단** | — |

**동점 처리:** ① 성수기 발주창 임박도(가까울수록 우선) ② 1접점 다브랜드 효율(문서10 TOP12 소싱처 중복 브랜드 가점).

## 4. 확정 시 대표님 승인 판단 (기록)

- 마진 40% 최고 가중 — 순마진율 12% 진입이 최우선 KPI(문서1).
- 법적 안전도 이중 적용(게이트 + 점수) — 병행수입 상표 리스크(CUCCUINI 단독·폐쇄위험 등) 실재.
- 드롭십 가능 SKU에 리드타임 만점 — 무재고가 재고회전·현금회수 하드스탑 자동 충족.
