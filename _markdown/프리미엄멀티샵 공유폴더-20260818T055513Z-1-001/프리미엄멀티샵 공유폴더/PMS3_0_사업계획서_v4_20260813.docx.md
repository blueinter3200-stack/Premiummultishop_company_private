사 업 계 획 서

PMS 3.0 — Commerce Intelligence 전환 계획

"AI가 세계 공급망을 분석해, 지금 팔 가치가 있는 상품을 찾아낸다"

기업명: 프리미엄멀티샵 (Premium MultiShop)

작성 기준일: 2026년 8월 13일

용도: 정부 정책지원사업 신청 · 벤처기업확인(인증) · 특허 출원 근거 · 지식산업센터 입주 심사

총 사업비: 5.5억 원 (정부 지원사업 + 자기자금)

요약 (Executive Summary)

프리미엄멀티샵은 명품·스포츠·컨템포러리 브랜드와 프리미엄 뷰티·건강기능 영양제 등 프리미엄 상품군을 소싱·유통해 온 이커머스 리테일 기업으로, 월 매출 1억~2억 원, 약 10만 명의 자체 고객 DB, 2,900개 상품 운영 이력, 유럽 공급사 네트워크를 보유하고 있다. 본 계획서는 기존의 "사람의 감(感)으로 사서 파는" 유통 방식을 폐기하고, AI가 전 세계 공급망 데이터를 실시간 분석하여 "지금 팔 가치가 있는 상품"만을 선별·검증·판매하는 Commerce Intelligence 기업(PMS 3.0)으로의 전면 전환 계획을 담고 있으며, 정부 정책지원사업 신청, 벤처기업확인(혁신성장유형), 특허 출원, 지식산업센터 입주 심사의 근거 자료로 작성되었다.

핵심은 이미 가동 중인 자체 AI 의사결정 체계다. 당사는 2026년 7월부터 4개 AI(Claude·GPT·Gemini·Grok)를 오케스트레이션하는 멀티에이전트 바잉 채점 엔진(CI 엔진 v1.1)을 실전 운영하고 있으며, 순마진율 12% 미만·리드타임 45일 초과 등 6개 하드스탑 게이트를 통과한 상품만 발주하는 룰 기반 리스크 통제 구조를 문서화된 운영규칙으로 확립했다. 본 사업은 이 검증된 운영 체계를 ①판단의 신뢰도(Confidence Score)와 기대기여가치(원화 금액)까지 계산하는 Decision Engine v2, ②적용군-대조군 비교로 실제 증분 효과를 입증하는 실험(Experiment) 엔진, ③글로벌 표준 API(Google Merchant API, NAVER API HUB) 기반 데이터 파이프라인으로 시스템화하는 기술개발 사업이다.

본 사업의 최상위 성과지표는 매출 증가가 아니다. 같은 재고투자금으로 더 많은 기여이익을 만들고(증분 기여이익), 팔리지 않을 상품을 사지 않아 손실을 회피하며(회피된 재고손실), 재고를 더 빨리 현금으로 회수하는 것이다. 이 세 지표는 모두 자체 판매 데이터로 검증 가능하도록 실험 설계를 시스템에 내장한다.

II. 사업 전환의 배경 및 필요성

1. 기존 유통 방식의 구조적 한계

전통적 수입 리테일은 "바이어의 경험 → 대량 사입 → 재고 소진"의 구조다. 이 구조에서 수익성은 바이어 개인의 감에 의존하며, 판단이 틀리면 재고가 현금을 잠식한다. 당사 역시 순이익률 5% 미만이라는 실측 결과로 이 한계를 확인했다. 문제는 채널(오프라인→온라인)이 아니라 의사결정 방식이었다.

감에 의존한 바잉 → 성공/실패의 재현 불가, 조직 학습 부재

대량 사입 전제 → 재고회전 지연, 현금회수기간 장기화

고정비 중심 구조 → 매출 변동 시 손익 급락

명품·리셀 플랫폼(크림·머스트잇 등)과의 최저가 경쟁 → 마진 방어 불가. 최저가 경쟁의 끝은 공멸이다 — 대형 플랫폼 발란조차 이 구조를 견디지 못하고 무너진 것이 시장의 실증 사례

2. 시장 환경: AI 공급망 분석은 검증된 성장 시장

글로벌 공급망 AI 시장은 2026년 약 138억 달러에서 2035년 2,364억 달러로 연평균 37.3% 성장이 전망된다(Precedence Research, 2026년 기준). 국내 온라인쇼핑 거래액은 연간 240조 원 규모(통계청 온라인쇼핑동향조사, 2024년 기준)로, 상품 선별·소싱 의사결정의 데이터화는 유통업 전반의 구조적 전환 방향이다.

반면 국내 중소 유통·셀러 시장에는 "무엇을 소싱할 것인가"를 데이터로 검증해 주는 서비스가 사실상 부재하다. 대형 플랫폼은 자사 판매 데이터를 외부에 제공하지 않으며, 개별 셀러는 감과 커뮤니티 정보에 의존한다. 실제 리테일 운영 데이터와 AI 분석 체계를 모두 보유한 사업자가 이 공백을 선점할 수 있다.

3. 왜 당사가 할 수 있는가 (준비된 전환)

실전 검증된 AI 운영 체계 — 4-AI 멀티에이전트 바잉 채점 엔진(CI 엔진 v1.1)을 2026년 7월부터 실제 바잉 의사결정에 적용, 채점 규칙·가중치·게이트가 문서화되어 재현 가능

데이터 자산 — 10만 고객 DB, 2,900개 상품 판매이력, 오프라인 상담·주문 데이터

공급망 네트워크 — 유럽 API 연동형 공급사 100개 발굴 리스트, 중국·홍콩 드롭시핑 파트너, 국내 사입처

리스크 통제 문화 — 순마진 12%·리드타임 45일·재고회전 90일 등 6개 하드스탑을 전 의사결정에 강제 적용

4. 정책 정합성

본 사업은 정부의 AI 확산·중소기업 디지털 전환·유통 선진화 정책 방향과 직접 부합한다. AI 바우처, 창업성장기술개발 R&D, 지자체·유관기관 디지털전환 지원사업 등 AI 도입·확산 지원사업의 지원 취지에 해당한다. 또한 자체 개발 AI 시스템(CI 엔진)과 데이터 자산 기반의 사업 구조는 벤처기업확인(혁신성장유형)의 기술 혁신성·사업 성장성 평가 요소에 부합하며, 소프트웨어 개발·정보서비스 중심의 사업 전환은 지식산업센터 입주 대상 업종 요건과도 정합적이다. 전통 유통업의 AI 전환이라는 대표적 디지털 전환(DX) 사례로서 정책 목적 적합성이 높다.

①·②가 현금흐름과 학습 데이터를 만들고, ③이 축적된 인텔리전스를 한계비용 없이 외부 판매하는 구조다. 자체 리테일은 CI 엔진의 상시 실증 무대(proving ground) 역할을 하므로, 경쟁사가 모방하기 어려운 "실판매 데이터로 검증된 추천"이라는 차별점이 유지된다.

IV. 핵심 기술 및 기술개발 계획

1. 기술 구성 요소

당사의 기술은 "논문 단계"가 아니라 실전 운영 중인 의사결정 체계를 소프트웨어로 시스템화하는 것이다. 이미 확립된 규칙·프로세스가 있으므로 개발 리스크가 낮고, 요구사항이 명확하다.

1-1. CI 엔진 — 멀티에이전트 AI 바잉 채점 시스템 (v1.1 운영 중)

구조: 4개 AI(Claude·GPT·Gemini·Grok)에 역할을 분담(재무판단·정량채점·멀티모달 트렌드·실시간 반론)시켜 토론·교차검증(adversarial) 후 단일 랭킹으로 수렴

채점: 2단 구조 — ①하드스탑 게이트(탈락/보류 자동 판정) ②가중점수(순마진율 40%·수요신호 20%·법적 안전도 15%·리드타임 15%·소싱조건 10%) 100점 환산

등급→액션 자동 연결: 85점 이상 즉시 실행 / 70~84 무재고 파일럿 / 50~69 보류 / 50 미만 중단

개발 과제: 현재 반자동(AI 오케스트레이션+수동 데이터 입력) → 데이터 자동 주입·채점 자동화·대표 승인 대시보드로 시스템화

1-2. 글로벌 공급망 데이터 파이프라인

유럽 공급사 100개 발굴 리스트 기반 API 연동(재고·가격·품절 실시간 동기화), DDP·리드타임·정품 증빙 조건 데이터베이스화

자사 판매 데이터 자동 수집: Cafe24 Admin API(읽기 전용) + 자동화 도구로 일일 적재 체계 구축 중(2026년 8월 착수)

수요신호 수집기: 국내 플랫폼 랭킹·검색 트렌드·SNS 반응·자사 카카오 문의를 표준 스키마로 통합

1-3. Decision Engine v2 — 점수가 아니라 돈과 신뢰도로 끝나는 3단 의사결정

단순 채점 모델은 특정 변수의 스케일이 다른 변수를 압도하거나, 데이터가 부족한 후보가 우연히 고득점하는 구조적 결함이 있다. 이를 방지하기 위해 의사결정을 3단으로 분리한다. 게이트를 통과하지 못하면 점수와 무관하게 실행하지 않고, 최종 판단은 점수가 아니라 원화 금액(기대기여가치)으로 내린다.

1단계 Hard Gate — 다음 기준 중 하나라도 미달이면 채점 없이 자동 처리한다.

| 게이트 | 기준 | 판정 |
| --- | --- | --- |
| 순마진율 | 관부세·수수료·환율 차감 후 12% 미만 | 자동 탈락 |
| 법적 안전도 | 정품 인보이스·통관·상표·AS 중 하나라도 불명확 | 자동 탈락 |
| 공급·데이터 존재 | 공급 불가 / 가격·원가 데이터 부재 | 탈락·보류 |
| 리드타임 | 45일 초과 | 자동 탈락 |
| 재고회전 예상 | 90일 초과 | 자동 탈락 |
| 데이터 신뢰도 | 0.70 미만 | 보류(재검증) |
| 단일 투자금 | 가용현금의 30% 초과 | 대표 승인 필요 |


2단계 기회점수 + 판단 신뢰도 — 게이트 통과분을 0~100점으로 정규화 채점(수요·구매의도·이익·공급·회전·CRM 적합은 가점, 경쟁·반품·가격·현금 리스크는 감점)하되, 같은 판단에 대해 "이 판단을 얼마나 믿어도 되는가"를 Confidence Score로 별도 산출한다. 신뢰도에는 데이터 신선도, API 정상 여부, 가격 샘플 수, 검색 데이터량, 과거 예측 정확도가 반영된다. 기회점수 92점이라도 신뢰도 43이면 자동발주를 금지하고 데이터 보강으로 회송한다 — AI 자동화 오판 사고를 구조적으로 차단하는 이중 안전장치다.

3단계 기대기여가치(ECV) — 최종 사입 판단은 점수가 아니라 돈으로 끝낸다. 예상 T일 판매수량 × SKU당 CM2에서 예상 반품손실, 가격인하 손실, 재고보유비용, 광고·콘텐츠 비용, 자본비용을 차감한 원화 금액으로 판단한다. CM2는 판매가에서 상품원가, 해외운송·통관, 결제·플랫폼 수수료, 할인, 배송지원, 예상 반품비용, 광고비까지 차감한 값으로 정의해 "검색량이 많아 매출은 늘지만 돈은 안 남는 상품"을 걸러낸다. 마지막으로 Portfolio Optimizer가 재고투자금 배분과 현금 묶임(Cash Lock-up)을 제한해 S/A/B/C/D/HOLD/STOP 등급을 확정하고, 등급별로 자동화 정도를 차등한다(S: 간편 승인, B: 소량 테스트, HOLD: 데이터 부족 시 대기).

1-4. CRM 인텔리전스

10만 고객 DB의 세그먼트화(VIP·Active·Dormant 등 11개 세그먼트)와 RFM 분석 — 수요신호의 1차 데이터원

카카오 CRM 기반 개인화 제안: 구매이력×신상품 매칭, 캠페인별 기여이익 측정

개인정보보호: 수신동의 게이트 절차 운영, 광고성 정보 발송 요건은 법률 검토 병행

1-5. 데이터 연동 표준 — 플랫폼 API 변경에 견디는 설계

외부 플랫폼 API는 수시로 변경·종료된다. 실제로 네이버 쇼핑 검색 API는 2026년 7월 31일 종료되었고 검색어 트렌드·쇼핑인사이트는 NAVER API HUB로 이관되었다(네이버 개발자센터 공지 기준). 당사 설계는 이 변경을 이미 반영하고 있으며, 특정 API 종속을 피하는 것을 원칙으로 한다.

| 연동 대상 | 표준 채택 | 설계 원칙 |
| --- | --- | --- |
| Google | Merchant API(Content API 공식 후속) 중심 — Product·Inventory·Data Sources·Reports, Search Console API, GA4 | 피드 등록·재고 동기화·성과 수집을 프로그램으로 관리, 구조화 데이터(Product)와 피드 동시 제공으로 검색·쇼핑·이미지·Lens 노출 자격 극대화 |
| 네이버 | NAVER API HUB — Search Trend·Shopping Insight | 종료된 쇼핑 검색 API 의존 설계 배제, 경쟁가격 수집은 승인된 데이터 소스로 별도 확보 |
| 자사·공급망 | Cafe24 Admin API(읽기 전용), 해외 공급처 API, 카카오 CRM | 원본 데이터 기준일 기록, 쓰기 작업은 승인 매트릭스 적용 |
| 공통 안정성 | retry·queue·idempotency(중복 실행 방지) 내장 | API 실패를 단순 중단으로 처리하지 않고 재시도 큐로 복구, 동일 오류 2회 시 자동 실행 중단 후 수동 검증 모드 |


1-6. Evidence 기반 콘텐츠 생성 — 대량 AI 콘텐츠의 함정 회피

AI로 페이지를 대량 생성해 검색 트래픽을 얻는 접근은 검색엔진의 스팸 정책(scaled content abuse)에 저촉될 위험이 있다. 당사의 콘텐츠 에이전트는 "글쓰기 AI"가 아니라 자사만 보유한 1차 데이터를 근거로 하는 Evidence 기반 커머스 콘텐츠 생성기로 설계한다. 실제 재고·색상·사이즈 보유 현황, 실제 가격 변동 이력, 브랜드별 판매속도, 실제 반품 사유와 사이즈 문의, 자체 촬영 이미지, 상품검수 정보를 콘텐츠에 결합해 — 인터넷 정보의 재요약이 아닌, 실판매 데이터에서만 나올 수 있는 독점적 콘텐츠를 생산한다. 이는 생성형 AI 검색 시대에 검색엔진이 요구하는 "고유하고 유용한 콘텐츠" 기준에 부합하는 장기 자산 전략이다.

2. 성과 입증 체계 — 증분(Incremental Lift) 검증 엔진

"시스템을 적용해서 실제로 돈을 더 벌었는가"는 검색 클릭 증가만으로 답할 수 없다. 시즌 효과와 시장 전체의 등락이 섞이기 때문이다. 당사는 성과 입증을 시스템 기능으로 내장한다. 유사한 브랜드·가격대·재고상태의 SKU를 적용군과 대조군으로 나누어 운영하고, 증분 효과를 다음과 같이 산출한다.

증분 효과(Lift) = (적용군 사후 − 적용군 사전) − (대조군 사후 − 대조군 사전)

| 검증 대상 | 적용군 vs 대조군 | 측정 지표 |
| --- | --- | --- |
| AI 추천 바잉 | AI 추천 사입 SKU vs 기존 방식 바잉 SKU | 판매속도, CM2, 재고회전, 회수기간 |
| SEO·구조화 데이터 | 기술 SEO 적용 상품군 vs 미적용 대조군 | 검색 노출·클릭·전환, 검색 유입 CM2 |
| 콘텐츠 | Evidence 콘텐츠 연결 상품 vs 대조군 | 콘텐츠 경유 전환율, 상품페이지 이동 |
| CRM | 추천 발송 고객 vs 미발송 Holdout 고객 | CRM 증분매출·증분 기여이익, 재구매율 |


도입 순서도 검증 우선이다. 먼저 실제 구매 없이 Shadow Mode로 AI 추천을 기록해 실판매 결과와 비교하고, 예측력이 확인된 뒤에만 소규모 SKU에 실사입을 적용하며, 데이터 신뢰도가 충분한 S급 영역부터 단계적으로 자동화를 확대한다. "AI 탐지 → AI 사입 → 자동 공개"가 아니라 "AI 탐지 → AI 추천 → 사람 승인 → 결과 학습"에서 출발하는 것이 원칙이다.

조회수·클릭 같은 중간 지표가 좋아도 회사가 재고 손실을 보는 상황을 방지하기 위해, KPI를 경영-커머스-시스템 3단으로 분리해 관리한다. 최상위는 언제나 경영 KPI다.

| 계층 | KPI | 의미 |
| --- | --- | --- |
| ① 경영 KPI(최상위) | 증분 기여이익(Incremental CM2) · 회피된 재고손실 · GMROI(재고투자 대비 총이익) · 현금회수일수 · 재고회전 · 반품 반영 순수익 | 시스템이 실제로 추가로 만든 돈과, 사지 않아 지킨 돈 — 대조군 실험으로 산출 |
| ② 커머스 KPI | 검색 유입 매출·기여이익 · 상품 전환율 · 콘텐츠→상품 이동률 · CRM 증분 기여이익 · 재구매율 | 채널·콘텐츠·CRM 활동이 경영 KPI로 이어지는 중간 경로 |
| ③ 시스템 KPI | 피드 정확도(가격·재고 일치) · 상품 승인율 · 대표 URL(canonical) 정확도 · 데이터 신선도 · 판단 신뢰도(Confidence) · AI 예측 오차 | 데이터·시스템 품질 — 이 계층이 무너지면 상위 KPI를 신뢰할 수 없음 |


X. 리스크 분석 및 대응

| 리스크 | 내용 | 대응 및 중단 조건 |
| --- | --- | --- |
| 법적 (병행수입·통관·상표) | 정품 분쟁, 상표권, 통관 책임, AS 책임 불명확 거래 | 법적 안전도 게이트로 사전 차단(불명확 시 자동 탈락). 정품 인보이스·통관 증빙 없는 거래 금지. 필요 시 전문가(관세사·변리사) 검토 |

| 기술 (개발 지연·AI 오판) | 시스템 개발 지연, AI 채점 오류, 외부 플랫폼 API 변경·종료 | 이미 운영 중인 프로세스의 시스템화로 요구사항 리스크 낮음. AI 판단은 Hard Gate + 판단 신뢰도(Confidence) 미달 시 자동발주 금지 + 대표 승인의 삼중 통제. API 변경은 표준 API(Merchant API·NAVER API HUB) 채택과 retry·queue 설계로 대응(네이버 쇼핑검색 API 종료 기반영) |

전사 공통 중단 조건: 동일 오류 2회 반복 시 해당 자동화 중단, 캠페인 기여이익 적자 시 축소·중단, 목표 판매속도 50% 미만 14일 지속 시 발주 중단. 이 중단 규칙들은 이미 사내 운영규칙으로 문서화되어 시행 중이다.

XI. 기대 효과 및 정책 기여

전통 유통업 AI 전환의 실증 사례 — "AI 도입 컨설팅"이 아닌, 자기 사업으로 검증한 전환 모델을 B2B로 확산

중소 셀러 생태계 기여 — 감에 의존하던 중소 셀러·리테일러에게 데이터 검증 소싱 인프라 제공 (2028년 구독 50개사 목표)

고용 창출 — AI·데이터 엔지니어 등 3~4명 신규 채용 + 계약 기반 전문가 네트워크 확대

수입 유통 선진화 — 정품 증빙·통관 투명성을 게이트로 강제하는 컴플라이언스 내재화 모델

재무 건전성 — 성장할수록 재고·현금 부담이 줄어드는 무재고·무형 매출 중심의 지속 가능 구조

기술 자산화 — BM 특허·상표·SW 저작권 확보와 벤처기업확인으로 기술기업 전환을 제도적으로 공인

맺음말

프리미엄멀티샵은 오프라인 매장 기반의 리테일러에서 출발해, 온라인 전환(PMS 2.0)을 거쳐, AI가 세계 공급망을 분석해 지금 팔 가치가 있는 상품을 찾아내는 Commerce Intelligence 기업(PMS 3.0)으로 전환한다. 이 전환은 구호가 아니라 이미 시작된 실행이다. 멀티에이전트 AI 채점 엔진은 실제 바잉에 적용되고 있고, 하드스탑 룰은 모든 의사결정을 통제하고 있으며, 데이터 파이프라인은 구축에 착수했다. 본 사업비는 검증된 운영 체계를 시스템으로 완성해 확장하는 데 사용된다. 순마진율 5% 미만의 유통기업이 15%의 데이터 기업으로 전환하는 이 계획에 대한 지원사업 선정, 벤처기업확인, 지식산업센터 입주 심사를 요청드린다.
