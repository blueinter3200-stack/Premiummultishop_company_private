5. Day 1 (2026-08-07) — 손익분기 ROAS 계산

이 장이 이 지침서에서 가장 중요합니다. 여기를 건너뛰면 나머지 전부가 무의미합니다.

5-1. 계산 3단계

1단계. 광고 전 공헌이익 구하기 (SKU 1개 기준, 1개 팔릴 때)

공헌이익(원)

= 판매가

− 상품원가(매입가 + 관부가세 + 국제·국내 운송비)

− 플랫폼 수수료(네이버 매출연동수수료 + 결제수수료)

− 국내 배송비(우리가 부담하는 금액)

− 포장비

− 반품·교환 충당금(판매가 × 예상 반품률 × 왕복배송+재처리비율)

공헌이익률(%) = 공헌이익 ÷ 판매가 × 100

2단계. 손익분기 ROAS 구하기

손익분기 ROAS(%) = 1 ÷ 공헌이익률 × 100

| 공헌이익률 | 손익분기 ROAS | 의미 |
| --- | --- | --- |
| 10% | 1,000% | 광고비 1만 원당 10만 원 팔아야 본전 |
| 15% | 667% |  |
| 20% | 500% |  |
| 25% | 400% | ROAS 300%는 적자 |
| 30% | 333% |  |
| 40% | 250% |  |


신입이 가장 많이 하는 착각: "ROAS 300%면 3배 벌었네" → 틀렸습니다. 공헌이익률 25% 상품이라면 ROAS 300%는 광고비 100만 원 써서 300만 원 팔았고, 그중 우리에게 남는 돈은 75만 원 → 25만 원 적자입니다.

3단계. 최대 허용 CPC 구하기

손익분기 CPC(원) = 공헌이익(원) × 구매전환율(소수)

목표 입찰가     = 손익분기 CPC × 0.6 ~ 0.7   ← 안전마진

예시(가상 수치, 실제 데이터 입력 필요)

판매가 300,000원, 공헌이익 60,000원(20%), 구매전환율 1.0%

손익분기 CPC = 60,000 × 0.01 = 600원

목표 입찰가 = 600 × 0.65 ≈ 390원

전환율을 모를 때: 자사몰·스마트스토어 과거 데이터가 없으면 0.5%를 보수적 가정값으로 쓰고, 반드시 "가정값(검증 필요)"이라고 표기합니다. 7일 후 실측치로 교체합니다.

13. D+7 판정 (2026-08-20) — 유지 / 중지 / 증액

13-1. 판정 계산 (SKU별로 각각)

① 광고 후 순이익(원) = (광고매출 × 공헌이익률) − 광고비

② 실제 ROAS(%)      = 광고매출 ÷ 광고비 × 100

③ 실제 CVR(%)       = 주문수 ÷ 클릭수 × 100

④ 실제 CPC(원)      = 광고비 ÷ 클릭수

13-2. 판정표 (①번 값 기준으로 먼저 판정)

| 조건 | 판정 | 조치 |
| --- | --- | --- |
| 광고 후 순이익 > 0 & 순마진율 12% 이상 & 재고 충분 | 증액 후보 | 대표 승인 후 +20~30%만 증액 (2배 증액 금지) |
| 광고 후 순이익 0 근처(±10%) | 유지 + 개선 | 입찰가 그대로, 상품명·이미지·제외검색어만 개선 후 7일 재측정 |
| 광고 후 순이익 < 0 & 클릭 100회 이상 | 중지 | 해당 소재 OFF, 원인 분류 후 기록 |
| 클릭 30회 미만 (표본 부족) | 판정 보류 | 7일 더 집행하되 예산 상향 금지 |
| 노출 3일 연속 0 | 중지 | 상품 승인·품질·입찰 점검 후 재등록 |

18. 문제해결 FAQ

Q1. 광고를 켰는데 노출이 0입니다. ①상품 승인 상태(검수 반려 여부) ②입찰가가 최소 입찰가 미만인지 ③쇼핑몰 연동 상태 ④상품 판매중지 여부 ⑤예산 소진 여부 순으로 확인합니다. 그래도 0이면 24시간 대기 후 재확인(반영 지연 가능).

Q2. 클릭은 많은데 구매가 없습니다. 상품 문제가 아니라 가격·상세페이지·검색어 불일치 문제일 확률이 높습니다. ①검색어 보고서에서 무관 검색어 확인 → 제외 ②네이버 쇼핑에서 동일 상품 최저가 확인 ③상세페이지에 사이즈·정품·교환 정보가 있는지 확인.

Q3. ROAS가 500%인데 순이익이 마이너스입니다. 왜죠? 공헌이익률이 낮기 때문입니다. 공헌이익률 15%면 손익분기 ROAS가 667%이므로 500%는 적자입니다. 손익분기 ROAS는 상품마다 다릅니다.

Q4. 예산이 오전에 다 소진됩니다. 입찰가가 높거나 일예산이 낮습니다. 우선 예산을 늘리지 말고 입찰가를 낮춰 하루 종일 노출되게 조정한 뒤, 시간대별 전환을 확인합니다. 예산 증액은 대표 승인 사항입니다.

Q5. 전환 데이터가 안 보입니다. 2장 C1(프리미엄 로그분석)이 미가동 상태일 가능성이 큽니다. 이 상태에서는 판정 자체가 불가능하므로 개발 담당에게 4-1의 요청문을 보내고, 해결 전까지 예산을 늘리지 않습니다.

Q6. 경쟁사가 우리보다 훨씬 싼데 어떻게 하나요? 가격을 따라 내리지 않습니다. 프리미엄멀티샵의 방어 영역은 정품 증빙·국내 재고 당일발송·일대일 상담·A/S·세탁·수선입니다. 이 조건을 확장소재와 상세페이지에서 명시하는 것이 먼저이고, 가격 인하는 5% 초과 시 대표 승인 사항입니다.

Q7. 다른 담당자가 설정을 바꾼 것 같습니다. 변경 이력을 확인하고 즉시 팀장에게 보고합니다. 광고 계정은 1인 운영이 원칙이며, 모든 변경은 일일 기록표에 남깁니다.
