Part 0. 대표님 요약 — 1페이지

한 줄 결론

제한 테스트 (즉시 확대 아님)

Google 검색광고 '운영 OS'는 만들 가치가 높습니다. 다만 지금 바로 광고비를 늘리는 것은 반대합니다.

이유는 두 가지입니다. ① 구매 전환 추적이 아직 검증되지 않았습니다(문서 19번 픽셀 판정 전 항목 불합격).

② 현재 순마진율 5% 미만 구조에서는 대부분의 SKU가 '허용 CPC' 계산을 통과하지 못합니다.

따라서 ①측정 복구 → ②브랜드검색 방어 1개 캠페인(소액) → ③AI 읽기전용 감사 → ④고마진 SKU 확대 순서로 갑니다.

숫자로 본 근거 — 왜 지금 확대하면 안 되는가

워크북 01시트로 실제 계산한 결과입니다. (판매가·원가는 대표적 가정치이며, 실제 원가로 교체 시 결론이 바뀔 수 있습니다.)

| 예시 상품 | 판매가 | 건당 기여이익 | 기여이익률 | 허용 CPA | 허용 CPC | 판정 |
| --- | --- | --- | --- | --- | --- | --- |
| 명품 패딩 | 1,200,000원 | 192,400원 | 16.0% | 48,400원 | 484원 | D · 광고금지 |
| 명품 스니커즈 | 450,000원 | 72,650원 | 16.1% | 18,650원 | 224원 | D · 광고금지 |
| K-Beauty 세트 | 89,000원 | 33,893원 | 38.1% | 23,213원 | 464원 | B · 소액테스트 |


핵심: 명품 카테고리는 클릭 1번에 224~484원까지만 쓸 수 있습니다. 그런데 '몽클레어 패딩' 같은 브랜드 키워드의 실제 CPC는 통상 700~2,000원대입니다. 즉 지금 구조로는 검색광고로 신규 고객을 사 오면 팔수록 손해입니다.

반대로 브랜드검색(자사 상호 '프리미엄멀티샵'을 검색한 사람)은 CPC가 낮고 전환율이 높아 유일하게 즉시 성립하는 영역입니다. 그래서 여기서 시작합니다.

Part 1. 먼저 알아야 할 것 — 초보자용 용어사전

이 문서에 나오는 모든 용어를 여기서 설명합니다. 모르는 단어가 나오면 이 표로 돌아오십시오.

1-1. 광고 기본 용어

| 용어 | 쉬운 설명 | 우리에게 왜 중요한가 |
| --- | --- | --- |
| 노출 (Impression) | 내 광고가 화면에 보인 횟수. 아직 돈은 안 나갑니다. | 많다고 좋은 것이 아닙니다. 클릭이 없으면 광고 문구가 나쁘다는 뜻입니다. |
| 클릭 (Click) | 고객이 광고를 눌러 우리 사이트로 들어온 횟수. 이때 돈이 나갑니다. | 클릭 = 지출. 클릭당 얼마인지가 손익의 출발점입니다. |
| CPC | 클릭 1번에 지불한 금액. Cost Per Click. | 이 지침서의 핵심 지표. 허용 CPC를 넘으면 무조건 중단합니다. |
| 전환 (Conversion) | 클릭한 사람이 실제로 '구매'한 것. | 우리에게 전환 = 구매 완료. 장바구니 담기는 전환이 아닙니다. |
| 전환율 (CVR) | 클릭한 사람 중 몇 %가 샀는가. 100번 클릭에 1명 사면 1%. | 허용 CPC를 계산하는 필수 값입니다. |
| CPA | 구매 1건을 만드는 데 든 광고비. Cost Per Acquisition. | 광고비 ÷ 구매건수. 허용 CPA를 넘으면 적자입니다. |
| ROAS | 광고비 1원당 매출이 몇 원 나왔는가. 매출 ÷ 광고비. | ROAS만 보면 안 됩니다. 매출이지 이익이 아닙니다. |
| 기여이익 | 매출에서 원가·수수료·배송·반품·광고비를 다 뺀 진짜 남은 돈. | 우리는 이 숫자로만 판단합니다. |
| 손익분기 ROAS | 이 배수보다 ROAS가 낮으면 팔수록 손해가 되는 기준선. | 판매가 ÷ 건당 기여이익. 워크북이 자동 계산합니다. |
| 키워드 | 우리가 '이 말로 검색하면 광고를 보여달라'고 등록한 단어. | 너무 넓게 잡으면 돈이 샙니다. |
| 검색어 (Search Term) | 고객이 실제로 검색창에 친 말. 키워드와 다릅니다. | 여기가 돈이 새는 곳입니다. 매주 반드시 봅니다. |
| 제외 키워드 | '이 말로 검색한 사람에게는 광고를 보여주지 마라'는 차단 목록. | 가장 확실한 광고비 절감 수단입니다. |
| 광고그룹 | 비슷한 키워드끼리 묶은 상자. 이 안에 광고 문안이 들어갑니다. | 우리는 상품 1개 = 광고그룹 1개 원칙으로 갑니다. |
| 캠페인 | 광고그룹들을 묶은 상위 단위. 예산·지역·입찰을 여기서 정합니다. | 예산 폭주를 막는 설정이 전부 여기 있습니다. |
| 일예산 | 하루에 쓸 상한 금액. | 설정 실수로 폭주하는 것을 막는 첫 번째 방어선입니다. |
| MCC / 관리자 계정 | 여러 광고계정을 한곳에서 관리하는 상위 계정. | API 권한을 받으려면 필수입니다. |
| 랜딩페이지 | 광고를 클릭했을 때 도착하는 페이지. | 홈으로 보내면 안 됩니다. 반드시 그 상품 상세페이지로 보냅니다. |
| SKAG | 키워드 1개 = 광고그룹 1개 구조. Single Keyword Ad Group. | 전 상품에 쓰면 관리 폭발. 고마진·고의도 상품에만 씁니다. |
| API | 사람이 화면을 클릭하는 대신, 프로그램이 직접 데이터를 주고받는 통로. | AI가 광고 데이터를 읽어오는 데 씁니다. |
| MCP | AI(Claude)가 외부 도구·데이터에 연결되는 표준 방식. | Google이 공식 MCP 서버를 제공합니다 (읽기 전용). |


1-2. 이 지침서가 지키는 3가지 원칙

원칙 1 — 측정이 먼저다

구매 전환 추적이 정확한지 확인되기 전에는 광고비를 늘리지 않습니다.

쉬운 비유: 연료계가 고장난 차로 장거리를 달리지 않는 것과 같습니다.

원칙 2 — ROAS가 아니라 기여이익이다

ROAS 5배여도 원가율이 85%면 적자입니다. 매출은 착시입니다.

모든 증액·중단 판단은 워크북 04시트의 '기여이익'과 '기여이익률'로만 합니다.

원칙 3 — AI는 읽고, 사람이 바꾼다

1단계에서 AI에게 절대 쓰기 권한을 주지 않습니다. 데이터를 읽고 분석·추천만 하게 합니다.

실제 변경(예산·입찰·게시)은 사람이 승인 후 손으로 합니다. 3개월 무사고 후에 자동화를 검토합니다.

Part 5. 판단 규칙 — 늘릴까, 멈출까

5-1. 허용 CPC 계산법 (이 지침서의 심장)

| 단계 | 계산식 | 예시 (명품 패딩) |
| --- | --- | --- |
| ① 건당 기여이익 | 판매가 − 상품원가 − (판매가×수수료율) − 배송비 − (판매가×반품충당율) − 포장운영비 | 1,200,000 − 900,000 − 39,600 − 5,000 − 60,000 − 3,000 = 192,400원 |
| ② 기여이익률 | ① ÷ 판매가 | 192,400 ÷ 1,200,000 = 16.0% |
| ③ 최소 확보 이익 | 판매가 × 12% (하드스탑) | 1,200,000 × 12% = 144,000원 |
| ④ 허용 CPA | ① − ③ | 192,400 − 144,000 = 48,400원 |
| ⑤ 허용 CPC | ④ × 구매 전환율 | 48,400 × 1.0% = 484원 |
| ⑥ 판정 | 실제 CPC > 허용 CPC 이면 광고 금지 | 실제 CPC 900원 > 484원 → D등급 · 광고금지 |


이 계산을 상품마다 하지 않고 광고를 켜는 것이, 우리가 지금까지 마진을 잃어온 가장 큰 이유입니다. 워크북 01시트에 값만 넣으면 자동으로 나옵니다.

5-2. 증액 / 유지 / 중단 규칙

| 판정 | 3가지 조건 | 조치 | 권한 |
| --- | --- | --- | --- |
| 증액 | ① 기여이익 > 0  ② 기여이익률 ≥ 12%  ③ 전환 5건 이상 (셋 모두 충족) | +10~20%만 인상. 한 번에 2배 금지 | 대표 승인 |
| 유지 | 기여이익 > 0 이지만 이익률 12% 미만, 또는 전환 5건 미만 | 증액 금지. 제외 키워드·랜딩페이지·문안부터 개선 | 담당자 자동 |
| 중단 | 기여이익 ≤ 0 이 7일 지속, 또는 허용 CPC 초과 | 즉시 일시중지 후 보고 | 담당자 자동 |


증액할 때 흔히 저지르는 실수

① ROAS가 높다고 바로 2배 증액 → 자동입찰 학습이 초기화되어 성과가 무너집니다. +10~20%씩만 올립니다.

② 증액 후 3일 만에 판단 → 최소 7일, 가능하면 14일 데이터를 봅니다.

③ 여러 캠페인을 동시에 증액 → 무엇이 원인인지 알 수 없게 됩니다. 한 번에 1개만 바꿉니다.

5-3. 언제 SKAG(키워드 1개 = 광고그룹 1개)를 씁니까

영상에서 강조하는 SKAG는 강력하지만, 상품 2,900개에 적용하면 관리가 불가능하고 각 그룹에 데이터가 쌓이지 않아 오히려 성과가 나빠집니다.

| 적용 대상 | 조건 | 이유 |
| --- | --- | --- |
| SKAG 적용 | ① 워크북 01시트 판정 A등급  ② 월 검색량 1,000회 이상  ③ 재고 3개 이상  ④ 전용 상세페이지 있음 | 검색어-광고-랜딩을 정확히 맞출 가치가 있는 소수의 상품 |
| 일반 광고그룹 | 같은 브랜드·카테고리 5~10개 키워드를 하나로 묶음 | 데이터를 한곳에 모아 학습시킵니다 |
| 광고 안 함 | D등급 · 재고 없음 · 정품 증빙 불가 | 광고할수록 손해이거나 법적 위험이 있습니다 |


현실적 목표: 전체 2,900개 중 SKAG는 최대 10~20개. 나머지는 오가닉 SEO·콘텐츠·CRM으로 처리합니다 (프로젝트 문서 18번 GEO 로드맵 연계).
