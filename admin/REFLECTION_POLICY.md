# Administrator Reflection Policy

- Updated: 2026-09-06
- 정본 절차: llm-source/LLM_RUNTIME.md, WORK_GOVERNANCE.md, APPROVAL_GOVERNANCE.md

공식 회사 기준·역할·승인 규칙의 변경은 관리자만 수행한다. 관리자의 현재 명시적 자연어 검토·반영 요청도 실행 지시로 인정하되, 일반 대화를 자동 확정으로 바꾸지 않는다. 검토→변경안 기록→범위가 명확한 승인→실제 저장→재조회 순서는 유지한다.

아이디어/문제는 관리자가 특정 내용의 공식 채택을 지시한 경우만 반영한다. 대상 원문·정제본·공식 기준·현재 업무를 대조하고 필요한 변경만 적용한다. 공식 반영과 원기록 상태·pending index를 함께 갱신한다. 실제 해결 증거 없이 문제를 resolved로 표시하지 않는다. 단순 참고·전처리·인덱스 정리는 반영이 아니다.

업무확정은 회사 정책·요구사항 개정이다. 영상·기획 결과 수락과 게시·지출 승인은 범위를 나눈 결재 기록으로 처리한다. 완료 업무를 전부 COMPANY_OS에 누적하지 않는다.

현재 상태의 원장은 work/items다. 변경 시 CURRENT_WORK와 assistant/30-working을 원장 기준으로 갱신한다. 기존 상태·원본·이력을 보존한다. 역할별 기록·개인정보·실제 도구 권한 경계를 지킨다.

대표업무점검은 읽기 전용이며 저장 기록·현재 업무·미반영 연결·날짜·후속 질문만 정리한다. GitHub에 없는 대화나 실제 행동을 추정해 '안 했다'고 단정하지 않는다.
