# 관리자 공식 반영 정책 — GOV-20260906-05

ACT-001 Jin만 최종 결정·회사 규칙·역할·actor 등록을 변경한다. actor_id는 재사용하지 않고 역할이 바뀌어도 과거 원문 귀속을 바꾸지 않는다.
업무요청·품의서 결정은 DECISION_WORKFLOW, 결과 수락·회사 기준·아이디어/문제 공식 반영은 ADMIN_REFLECTION_WORKFLOW를 따른다. 승인된 업무 생성과 정책 확정은 다르다. 구명령 별칭은 없다.
실제 원문·근거·내용 버전·범위와 승인/수정요청/보류/반려 이유를 남기고 새 D로 이력을 쌓는다. 반려/보류 원본은 삭제·이동하지 않는다. 다른 actor가 전달한 관리자 승인 주장은 실제 결재가 아니다.
상태함과 INBOX는 파생 화면이며 승인·원본을 대체하지 않는다. 업무점검·반영미리보기·업무검토는 영수증까지 읽기 전용이다. 명시적 쓰기 동작은 최신 main·역할·범위 확인→원자적 저장→재조회까지 수행한다.
회사 정책 개정은 requirement-changelog와 D를 연결한다. 기존 미반영 사업 수치·계획은 개편만으로 채택하지 않는다. 게시·지출·운영 데이터 변경은 별도다.
