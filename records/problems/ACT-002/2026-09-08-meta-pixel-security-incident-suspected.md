# Meta 픽셀 외부 자산 연결·계정 침해 의심 보안 이슈

## 문제

대표님이 현재 대화에서 제시한 자료 요약에 따르면, 사내 광고 운영 영역의 Meta Pixel/데이터 세트에 회사 정상 구조와 맞지 않아 보이는 외부 자산 연결 정황이 있다. 문제 대상으로 제시된 데이터 세트는 `CĐ-HN / 647894930506901`, 소유자는 `Z799 / 386312022711352`이며, 생성 관련 정보로 `Kareen Gomeez / 2023-04-22`가 제시되었다.

또한 서로 관련 없어 보이는 해외 도메인 9개에서 이벤트를 현재도 수신하는 것으로 제시되었고, 화면상 광고계정 ID로 `455684045006286`과 `121104165361159`가 함께 언급되어 실제 회사 주력 광고계정 식별이 필요한 상태다.

이 기록은 **보안 사고 의심 문제의 보존**이며, 계정 탈취 또는 무단 광고비 사용이 확인되었다는 확정 기록이 아니다.

## 현재 상황 / 영향

### 현재 대화에서 제시된 사실·주장
- 데이터 세트 `CĐ-HN / 647894930506901`이 확인 대상으로 제시됨.
- 소유자 이름은 `Z799`, 소유자 ID는 `386312022711352`로 제시됨.
- 생성 관련 정보로 `Kareen Gomeez / 2023-04-22`가 제시됨.
- 회사와 직접 관련 없어 보이는 해외 도메인 9개에서 이벤트를 수신하는 정황이 제시됨.
- 광고계정 ID `455684045006286`과 `121104165361159`가 모두 관련 화면에서 확인된 것으로 제시됨.
- 정상 주력 후보 자산으로 `241213cafe24 / 449337224670661`이 제시되었으나, 정확한 자산 유형·소유·연결 관계는 이 저장 과정에서 독립 검증하지 않음.

### 예상 가능한 영향
- 과거 외부 대행사 또는 외부 비즈니스 자산 연결이 남아 있을 가능성.
- 외부 접근권한이 존재할 경우 광고계정·픽셀·데이터 세트·결제 관련 보안 위험 가능성.
- 관계없는 도메인의 이벤트가 섞이는 경우 광고 데이터 품질·타기팅·전환 측정에 영향을 줄 가능성.
- 실제 캠페인 생성·결제 권한 또는 무단 지출이 있었다면 재무 피해 가능성.

위 영향은 현재 문제 단계의 위험 가능성이며 실제 피해 규모로 확정하지 않는다.

## 원인 또는 확인 필요

1. Meta 비즈니스/광고계정 침해 또는 과거 계정 탈취의 잔존 연결.
2. 과거 외부 광고대행사·파트너가 연결해 둔 자산/권한이 정리되지 않은 잔재.
3. 계정 자체 침해 없이 외부 데이터 세트만 연결된 상태.

- `455684045006286`과 `121104165361159` 중 실제 회사 주력 광고계정이 무엇인지.
- 2023-04-22 이후 모르는 캠페인·광고세트·광고소재·결제·결제수단 변경·관리자 추가·파트너 추가 이력이 있는지.
