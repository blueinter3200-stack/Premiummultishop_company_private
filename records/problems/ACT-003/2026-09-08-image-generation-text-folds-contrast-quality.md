# 이미지 생성 시 텍스트 라인·의류 주름·명암 대비 품질 문제

## 문제

이미지 생성 결과에서 텍스트 라인이 자연스럽게 정리되지 않고, 의류 주름이 충분히 형성되지 않으며, 명암 대비도 약하게 표현되는 품질 문제가 제기되었다.

이 기록은 현재 대화에서 발견한 생성 품질 문제를 보존하는 것이며, 특정 생성 모델·프롬프트·도구가 원인이라고 확정하는 기록은 아니다.

## 현재 상황 / 영향

### 현재 대화에서 명시된 현상
- 텍스트 라인이 어색하게 보임.
- 의류 주름이 자연스럽게 잡히지 않음.
- 명암 대비가 충분하지 않음.

### 예상 가능한 영향
- 타이포그래피가 실제 광고·편집디자인처럼 정돈되지 않아 완성도가 낮아 보일 수 있음.
- 의류의 접힘·당김·원단 질감이 약해 소재감과 실루엣 전달력이 떨어질 수 있음.
- 하이라이트와 그림자 차이가 약하면 모델과 제품이 평면적으로 보일 수 있음.
- 결과적으로 실제 촬영 화보보다 AI 생성물처럼 보일 가능성이 커질 수 있음.

위 영향은 현재 문제를 바탕으로 한 해석이며 별도 비교 테스트로 검증된 결과는 아니다.

## 원인 또는 확인 필요

### 원인 가설 — 미확인
1. 텍스트 내용만 지정되고 줄바꿈·행간·자간·정렬·최대 행 폭 등 편집 조건이 충분히 고정되지 않았을 가능성.
2. 원단의 장력, 압축 주름, 자연스러운 드레이핑, 봉제선·접힘부 self-shadow 등 물리 묘사가 부족했을 가능성.
3. 조명 방향·강도·키라이트와 음영 차이·그림자 깊이가 충분히 지정되지 않았을 가능성.
4. 모델의 포즈·동작이 정적이라 의류가 당겨지거나 접히는 변형이 충분히 생기지 않았을 가능성.

### 추가 확인 필요
- 동일 상품·구도에서 텍스트 레이아웃 제약을 강화했을 때 개선되는지.
- 원단 주름·장력 조건을 강화했을 때 실제 의류 질감이 개선되는지.
- 방향성 키라이트와 더 깊은 그림자 조건을 넣었을 때 명암 대비가 개선되는지.
- 문제가 특정 생성 모델 또는 특정 프롬프트 구조에서 반복되는지.

## 해결 방향 후보

1. **타이포그래피 조건 구체화**
   - 텍스트 위치뿐 아니라 최대 행 폭, 줄바꿈 위치, 행간, 자간, 정렬 기준과 시각적 위계를 고정한다.

2. **의류 물리 묘사 강화**
   - natural draping, tension wrinkles, compression folds, fabric self-shadow, seam detail 등 원단의 실제 변형과 음영 조건을 명시한다.

3. **명암 대비 강화**
   - 한쪽 방향의 키라이트와 반대편 음영을 지정하고, 하이라이트·중간톤·그림자의 차이를 더 분명히 요구한다.

4. **영상용 프레임 일관성 보완**
   - 움직임에 따라 의류 주름이 프레임별로 자연스럽게 변화하도록 조건을 추가한다.

> 위 해결 방향은 현재 대화에서 도출된 후보이며, 실제 개선 효과는 별도 비교 생성 후 판단해야 한다.
