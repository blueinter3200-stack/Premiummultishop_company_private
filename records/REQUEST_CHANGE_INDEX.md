# Request Change Index — 관리자 요청 변경이력

개별 `records/request-changes/ACT-001/<R-ID>/<RC-ID>.json`이 정본이다. 이 파일은 검색용 파생 목차이며 승인·업무 원장이 아니다.
기준: GOV-20260906-04. 초기화 시점에는 실제 RC 이벤트가 없었다. 현재 이벤트는 아래 항목과 실제 RC 파일로 확인한다. 테스트 데이터는 이 목차에 넣지 않는다.

각 실제 이벤트의 RC-ID, R-ID, 변경자, 전/후 revision, RC 경로를 기록한다. 요청/RC와 동일 커밋으로 갱신한다.
