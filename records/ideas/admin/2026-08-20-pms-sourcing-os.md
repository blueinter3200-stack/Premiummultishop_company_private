# PMS Sourcing OS — Evidence-to-Revenue Buying Desk

## 아이디어

Premium MultiShop 전용으로, 단순 상품 수집·번역·대량등록이 아니라 **팔 가치가 있는 상품만 선별하고 수익·정품·권리·배송·반품·A/S를 검증한 뒤 승인된 상품만 등록하는 바잉·상품등록 OS**를 구축한다.

핵심 흐름은 다음과 같다.

상품 신호 → 동일 SKU 식별 → 판매자·공급처 비교 → 정품·재판매권·인보이스·통관 증거 → CM1·CM2 계산 → 대표 승인 → AI 상세페이지 → Cafe24 임시등록 → 주문·CARE·재구매 학습

대표 사용 흐름은 복잡한 운영 화면보다 아래 승인 중심으로 단순화한다.

상품 URL 붙여넣기 → 후보 저장 → 예상 수익·위험 확인 → 테스트 승인/보류/반려 → AI 상세페이지 확인 → Cafe24 임시등록 → 공개 승인

## 목적 / 왜 필요한지

- 많이 찾고 많이 등록하는 셀러소싱형 도구가 아니라, 실제 판매 가능성과 위험을 함께 검증하는 Premium MultiShop 전용 바잉 체계를 만든다.
- 상품 URL 하나를 출발점으로 공급처·원가·증거·수익·콘텐츠·등록·사후관리까지 하나의 운영 흐름으로 연결한다.
- 대표 승인과 HOLD·STOP을 중심에 두어, 자동화가 결제·발주·상품공개·가격·재고 같은 고위험 실행을 임의로 수행하지 않도록 한다.

## 핵심 화면

1. **시장신호 Inbox**
   - 네이버 공개 상품, 경쟁자 상품, 해외 플랫폼 상품
   - 판매 많은순·랭킹, 리뷰·가격·배송·재고
   - 고객 상담·재입고 요청

2. **동일 SKU 비교판**
   - 브랜드, 모델번호, 시즌, 색상, 사이즈, 상태, 구성품
   - 국내 판매가, 해외 구매가

3. **공급처·증거 Vault**
   - 상업 인보이스, 구매증빙, 정품 증거, 재판매권, 통관 자료
   - 구성품, 검수 사진, 배송·반품·A/S 책임

4. **구매 승인함**
   - 총 투자금, 실제 착지원가, 예상 판매가
   - CM1, CM2, 예상 현금회수기간, 최대 손실액
   - 배송일, 반품 위험, 정품·권리 상태
   - 승인 요청 / 보류 / 반려 / 소량 테스트 승인 / 발주서 초안
   - 결제와 발주는 최종적으로 사람이 직접 실행

5. **AI 상세페이지 스튜디오**
   - 생성 가능: 상품명, 한국어 번역, 핵심 요약, 소재·핏·관리 설명, 사이즈 안내, FAQ, SEO 메타, 카드뉴스, 숏폼 대본, 카카오 상담 문구
   - 생성 금지: AI 정품 판정, 공식 A/S 표현, 근거 없는 판매량·인기상품 표현, 확정 배송일, 관세·통관 책임, 환불·보상 조건, 권리 없는 이미지 게시

## READY · RARE · CARE 연결

- **READY**: 국내 실물재고·빠른 출고 상품 우선 노출
- **RARE**: 해외주문형·희소상품·조달 요청 관리
- **CARE**: 주문 후 검수·배송·반품·세탁·수선·A/S·재구매 연결

## 첫 검증 방식

첫 개발은 상품 1개를 끝까지 처리하는 테스트로 시작한다.

URL 1개 → 후보 등록 → 해외 공급처 비교 → CM1·CM2 → 증거 확인 → AI 상세페이지 → Cafe24 임시등록

이 1개 상품 흐름이 검증되면 5 SKU로 확대하는 방향이다.

## 기대효과

- 상품별 매입 판단 근거와 위험 증거를 한곳에서 비교할 수 있다.
- 대표는 복잡한 운영 대신 승인·보류·반려 판단에 집중할 수 있다.
- AI가 콘텐츠 제작을 지원하되 정품·권리·배송·환불 등 사람이 책임져야 하는 판단과 실행은 분리할 수 있다.
- 상품 등록 이후 CARE와 재구매 학습까지 연결해 소싱 판단을 실제 매출·운영 데이터로 되돌릴 수 있다.
