# 트렌드 검증형 AI 쇼핑쇼츠 자동 생산 시스템

## 아이디어
상품명 또는 상품 URL 하나를 입력하면 시장성 확인부터 광고 기획, 쇼츠 다변량 생성, 검수, 성과 측정, 다음 소재 개선까지 이어지는 AI 쇼핑 콘텐츠 생산 시스템을 만든다.

핵심은 단순한 AI 영상 제작 자동화가 아니라 다음 반복 구조를 만드는 것이다.

1. 상품/시장 데이터로 테스트할 상품을 고른다.
2. 상품의 타깃 고객과 구매 포인트를 분석한다.
3. 서로 다른 훅·모델·연출·카피를 가진 쇼핑쇼츠를 여러 개 생성한다.
4. 실제 성과를 측정한다.
5. 성과가 좋은 패턴을 다음 소재 생성에 다시 반영한다.

즉 `AI 쇼핑쇼츠 제작기`가 아니라 `AI 광고 소재 실험 엔진`으로 발전시키는 방향이다.

예시 소재 유형:
- 문제해결형
- 가성비형
- 놀라움형
- 비교형
- 후기/UGC형
- AI 한국인 모델형
- AI 외국인 모델형

## 목적 / 기대효과
- 한 상품에서 10~30개의 광고 소재를 빠르게 만들어 테스트한다.
- 촬영과 모델 섭외 의존도를 줄인다.
- 훅, 타깃, 모델, 구도, 카피를 다변량으로 실험할 수 있다.
- 성과가 좋은 광고 패턴을 데이터로 축적한다.
- 쇼츠뿐 아니라 릴스, 틱톡, 메타 광고 소재로 확장할 수 있다.
- 장기적으로는 사람이 매번 영상을 만드는 방식보다 AI가 소재를 계속 실험·개선하는 콘텐츠 팩토리를 구축한다.

## 관련 업무
초기 MVP 후보 흐름:

`상품 URL 입력`
→ 상품 정보 추출
→ 타깃/USP 분석
→ 쇼츠 콘셉트 10개 생성
→ 관리자 검수/선택
→ 이미지 또는 AI 모델 생성
→ 영상 생성
→ 대본·자막·CTA 생성
→ 검수용 결과물 출력

후속 확장 후보:
- 네이버 데이터랩 등 수요 데이터 기반 상품 후보 추천
- 판매 플랫폼 상품 데이터 연계
- 업로드 후 조회 유지율, 클릭률, 구매전환 등 성과 수집
- 승자 소재를 변형해 후속 소재 자동 재생성

첫 검증 실험 후보는 `상품 3개 × 소재 10개 = 30개` 수준으로 두고 제작비, 조회수, 3초 유지율, 완주율, 클릭률, 구매전환을 비교한다.

## 아직 미정인 부분
- 어떤 상품 데이터 소스를 자동 수집 대상으로 확정할지
- 어떤 영상/이미지 생성 모델을 기본 엔진으로 사용할지
- 생성 결과를 어디까지 자동 업로드할지, 어디에서 사람 검수를 둘지
- 성과 데이터를 어느 플랫폼에서 어떤 방식으로 회수할지
- 상품 이미지·상표 재현, AI 모델 광고 표현, 효능/과장 문구 등 광고 검수 정책
- 실제 구매전환 개선 여부와 경제성이 충분한지
