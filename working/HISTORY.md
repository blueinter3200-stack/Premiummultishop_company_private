# Working History

평소 LLM 기본 읽기 대상이 아니다. `CURRENT_WORK.md`의 주요 갱신 이력을 짧게 남긴다.

## 2026-08-19
- 회사 진행·협의 업무를 부서별 자동 분류하지 않고 `working/CURRENT_WORK.md` 한 파일의 최신판으로 관리하는 방식 채택.
- 대표님과 관리자가 모두 업무공유 가능하며, 관리자만 업무확정 및 공식 반영을 수행하도록 역할 분리.
- `/업무공유` 전 `/업무검토`를 필수 게이트로 추가. 최신 공식 회사 방향·확정 요구사항·CURRENT_WORK를 검토해 `PASS / 공유 가능`인 경우에만 공유하도록 확정.
- 업무검토 PASS는 공식 요구사항 확정이 아니라 CURRENT_WORK에 공유 가능하다는 의미로 분리.
- 기존 확정 기준의 변경안도 업무검토 → 업무공유 → 관리자 업무확정 순서로 처리하도록 확정.
- 업무공유 첨부자료도 원본 보존과 LLM용 normalized Markdown을 분리 저장하도록 확장.
