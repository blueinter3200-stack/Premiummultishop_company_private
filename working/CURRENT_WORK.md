# Current Work

- Repository: `https://github.com/jintonic1010/miracle_company_private`
- Updated: 2026-08-19
- Authority: current progress/discussion, not automatically official requirements

이 파일은 회사에서 **현재 실제로 진행·협의 중인 업무 전체의 최신판**이다. 부서별 자동 분류를 강제하지 않는다. `/업무공유` 때마다 기존 내용을 읽고 새 내용·수정·삭제·보류를 반영해 전체 파일을 최신 상태로 다시 정리한다.

## 진행 중

### 회사 OS 설계 및 대표님 보고 준비
- n8n을 회사 전체 OS의 뼈대로 두는 구조 정리 중.
- ERP/재고·물류, 시장리서치, 마케팅, CS, 세무·법률을 회사 부서 모듈로 연결하는 방향.
- 대표님과 관리자 ChatGPT가 같은 회사 기준과 진행상황을 공유할 수 있는 저장소/소스 구조를 구축 중.

### ERP / API 연동
- ERPNext와 InvenTree 중 최종 선택 필요.
- Cafe24, Naver SmartStore, Google 관련 API, 해외 공급처 API의 정확한 IN/OUT 및 이벤트 범위 조사 필요.
- ERP 개발자와 n8n/API 개발자가 사용할 공통 식별자 및 데이터 계약 정의 필요.

### 마케팅 운영 인력
- 마케팅 부서 모듈을 실제 운영할 사람의 역할과 채용 기준을 협의 중.
- 단순 광고 집행만 하는 역할보다 CRM, 커머스, ERP의 고객·상품·재고·매출 데이터를 활용할 수 있는 인력 방향을 검토 중.
- 직무명, 경력, 인원 구성 등은 아직 확정하지 않음.

## 협의 중 요구사항 후보

- 진행 업무는 부서별 파일로 자동 분류하지 않고 `CURRENT_WORK.md`에서 전체 최신판으로 유지한다.
- 대표님과 관리자 모두 `/업무공유`로 현재 업무를 갱신한다.
- 관리자가 `/업무확정`한 내용만 공식 요구사항과 회사 기준으로 승격한다.
- 확정 전 변경안이 기존 공식 기준과 다르면 LLM은 둘을 분리해 설명한다.
