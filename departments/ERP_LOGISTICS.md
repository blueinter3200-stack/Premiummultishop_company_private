# ERP / Inventory & Logistics Department

## 역할

회사의 상품, 재고, 주문, 판매, 고객, 구매, 공급처, 물류 운영 데이터의 Core.

## ERP 후보

- ERPNext
- InvenTree

최종 선택은 아직 미정이다.

## 주요 데이터

- product
- SKU / variant
- warehouse
- available / reserved stock
- inbound / outbound movement
- order / channel order
- customer / purchase history
- shipment
- cancellation / return / exchange
- supplier / purchase
- cost / settlement-supporting operational data

## 외부 연결

- Cafe24 ↔ ERP
- Naver SmartStore ↔ ERP
- Google-related systems ↔ ERP
- Foreign supplier API → ERP

## 다른 부서와의 관계

시장리서치, 마케팅, CS, 세무·법률 부서와 필요한 데이터를 양방향 교환한다.
