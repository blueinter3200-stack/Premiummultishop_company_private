# 선택적 작업지시·결정 알림 — GOV-20260907-01

## 정본과 파생물
D=결정, ASG=관리자 배정 사건, R/SUB/W=대상 원장이다. 결정 통지는 N-<D-ID>-<actor>, 작업지시 통지는 N-<ASG-ID>-<actor>로 records/notifications/<actor>/에 둔다. 같은 사건/수신자를 중복 생성하지 않는다.
notification-receipts는 실제 표시/확인 영수증, inbox·decision-views·assignment-views와 DECISION_INDEX는 조회판이다. 원본을 승인함·보류함·반려함으로 옮기지 않는다. 민감정보·관리자 비공개 메모를 복사하지 않고 actor 경로가 실제 계정 ACL을 대신한다고 말하지 않는다.

## 수신자와 최초 안내
대표 업무요청은 관리자 검토 대상이지 부사수의 미배정 할 일이 아니다. 초기 결정은 요청자/실제 대리 기록자에게만 보이고, 부사수에게 배정하면 ASG의 승인된 지시 요약으로 첫 안내를 생성한다. 부사수가 이미 구두 요청을 알았더라도 관리자 정식 배정은 별개 사건이므로 생략하지 않는다.
자기 계획안 결의와 배정 업무에 실제 영향을 주는 후속 보류/승인/해제는 해당 작성자/담당자에게 전달한다. 신규 배정/재배정은 새 담당자에게, 필요한 담당 해제는 이전 담당자에게 알린다. 관리자 자기 배정/결정은 기본 자기 알림을 만들지 않는다.
동일 배정 사실을 D 알림과 ASG 알림으로 중복 설명하지 않는다. 배정과 나중 계획 결의는 서로 다른 의미의 사건이므로 각각 안내한다. 배정은 아직 본 실행 허가가 아님을 표시한다.

## 확인 비용
새 대화 첫 실제 회사 업무, 같은 요청/계획/지시/업무 재개, 업무검토·업무요청·업무계획안제출·업무업데이트의 필요한 진입, 명시적 최신 상태 문의에서 자기 INBOX 하나를 확인한다. 잡담·명령 설명·대화 내 출력은 읽지 않는다.
동일 연속 업무 흐름에서는 inbox revision과 표시 N-ID를 대화 내 재사용하며 기본 30분 이내 재조회를 생략할 수 있다. 새 대상/명시적 최신 문의는 새로 확인한다. 시간 경과만으로 백그라운드 폴링하지 않고 시각 미확인에는 시간을 추정하지 않는다.
핵심 실제 실행/결정/업무업데이트 직전 최신 대상 D·ASG·계획 버전/범위 확인은 별도이며 INBOX 캐시가 승인 확인을 대신하지 않는다.
기본 페이지는 유효 미전달 최대20개, 사용자 표시는 관련/최신 최대3개+나머지 건수다. 초과는 more_count/페이지 포인터로 유지한다. 실제 결정 원문은 필요한 건만 추가 조회한다.

## 새 사건만 표시
의미 있는 D 결과/조건 변화, ASG 신규/재배정/담당 해제만 새 알림이다. 옛 보류/반려/배정을 소급해서 unread로 방송하지 않는다. 같은 이벤트 재시도·단순 조회는 새 알림이 아니다.
같은 대상/내용 버전/범위의 미전달 D가 최신 결정으로 대체되면 이전 사건은 기록에 보존하되 최신 유효 변화만 표시한다. 미확인 보류 뒤 승인되면 보류→승인으로 안내한다. ASG도 W별 최신 배정 체인을 따라 이미 해제된 지시를 신규 실행 지시로 알리지 않는다. r1 결과를 r2 결과로 쓰지 않는다.
아직 유효한 작업지시를 한 번 안내했다고 그 할 일을 없애지 않는다. assignment-views에는 실제 미완료/현재 배정 업무의 제목·승인된 지시·계획 상태·다음 행동이 남으며 완료/취소/재배정 때 파생 목록만 바뀐다.

## 표시/확인과 영수증
fetch는 unread를 바꾸지 않는다. 실제 사용자 대화에 해당 N을 표시한 후에만 delivered_at/presentation_ref를 남긴다. 사람의 명시적 확인 원문이 있을 때만 acknowledged_at/ack_source다. 자동 표시를 동의/읽음/수행 완료로 주장하지 않는다.
현재 허용된 쓰기 상황 또는 명시적 알림 확인 기록 요청에서 실제 표시한 N들만 영수증과 INBOX에 함께 저장한다. 표시하지 않은 나머지는 unread다. 확인 기록 실패는 미기록으로 알린다.
업무검토·업무점검·반영미리보기·출력·저장하지 마는 영수증도 쓰지 않는다. 이때 현재 대화 안에서만 반복을 막고 다음 허용 쓰기/명시 확인 때 표시분을 기록한다. 영속 기록이 없으면 새 대화에서 재표시될 수 있으며 전역 정확히 한 번 전달을 보장하지 않는다.
보류나 미완료 자체를 매번 독촉하지 않는다. 합의된 별도 리마인더 없이 날짜 경과만으로 N을 만들지 않는다. 현재 해야 할 일을 묻거나 같은 건 재개할 때 현재 상태를 설명하는 것은 옛 알림 재방송이 아니다.

## 저장/구현 경계
D/ASG/W와 관련 N/조회판을 같은 논리적 커밋으로 저장하고 재조회한다. 부분 실패면 동일 event/ID로 복구하며 인덱스만 성공이라고 하지 않는다.
같은 건 업무검토에서는 전달 상태와 무관하게 과거 이유·현재 차이를 확인한다. 옛 반려는 영구 금지가 아니며 계속 유효한 제한은 실제 관리자 근거로 확인한다.
이 구조는 다음 관련 업무 대화에서 조회/안내하는 방식이다. 문서·로컬 코드 저장만으로 다른 채팅방 메시지 전송·실시간 푸시·메일/n8n 연결·실제 사용자 확인을 완료했다고 말하지 않는다.
