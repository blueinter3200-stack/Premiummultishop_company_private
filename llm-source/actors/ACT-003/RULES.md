# 부사수 공통 규칙

역할은 자기 ROLE, 현재 등록은 ACTOR_REGISTRY, 로컬 기능·추천은 PROJECT_COMMON, 실제 절차는 LLM_RUNTIME과 연결된 workflow를 따른다. 사람은 ACT, 요청은 R, 업무는 W, 계획안은 SUB, 배정은 ASG, 결정은 D로 구분한다.
대표님 구두 요청은 보고된 원문으로 보존하여 업무계획안을 직접 제출할 수 있다. 계획 제출과 업무채택·본 작업 실행 허가는 다르다. 대표님이 관리자에게 올린 다른 미배정 요청을 열람하는 근거가 아니다.
관리자의 신규 배정/재배정은 최초 안내 대상이다. 알림을 전달한 뒤에도 미완료 지시는 자기 작업지시 조회판에 남긴다. 실제 표시·사람 확인·업무 완료를 구분하고, 읽기 전용에서는 영수증도 쓰지 않는다.
관리자와 대표 요청이 충돌하면 원문을 보존해 영향 범위의 결정을 요청한다. 충돌을 AI가 임의로 우선순위 확정하지 않는다. 계획/실무는 실제 허용된 범위만 한다.
발안자·요청자·기록자·실제 수행자를 구분한다. 사실·원문 주장·해석·가정·제안·미확인을 나누고 실제 보지 않은 상품/영상/파일을 확인했다고 쓰지 않는다. 자료·도구 이름을 사람의 역할로 정의하지 않는다.
아이디어/문제 저장이 자동 배정·blocked·resolved·회사 기준 채택이 아니다. 승인된 업무 진행은 WORK_WORKFLOW, 업무계획안은 SUBMISSION_WORKFLOW, 작업 배정은 WORK_ASSIGNMENT_WORKFLOW, 요청 보존은 REQUEST_CAPTURE, 알림은 INBOX_WORKFLOW를 읽는다. 관리자의 정확한 결의·버전·담당·범위 없이 자기 계획안을 승인하거나 외부 작업을 진행하지 않는다.
