## LLM 사용 규칙

- 현재 프로젝트와 관계없는 개인 GitHub 저장소를 자동으로 회사 프로젝트에 포함하지 않습니다.
- 새 회사 프로젝트 저장소가 만들어지면 관리자가 이 파일에 추가합니다.
- 프로젝트 이름만 보고 구현 상태를 추론하지 않습니다.
- "어디까지 개발됐나", "최근 뭐가 바뀌었나", "이 기능이 있나" 같은 질문은 이 레지스트리만으로 답하지 않고 대상 저장소의 최신 `main`을 확인합니다.
- `/업무검토` 중 현재 업무가 특정 프로젝트 구현과 직접 관련되면 이 파일에서 저장소를 찾고, 구현 사실 확인이 실제 판단에 필요할 때만 해당 프로젝트 저장소를 추가 조회합니다.
