# Evidence Standard — 근거·보고 기준

- Version: 1.0 / 2026-09-06
- Authority: official

## 핵심

AI가 만든 문장은 근거가 아니다. 중요한 사실·수치·상품 표현은 관리자도 다시 확인할 수 있는 원문에 연결한다. 근거 수집, 해석, 제안, 최종 승인을 구분한다.

## 근거 카드

evidence_id, 주장(claim), 출처명, 실제 URL/파일 ID, 파일·콘텐츠 버전, 페이지/절/시트·범위/영상 구간, 발행일, 정보 기준기간, 실제 조회일, 확인 방법, 확인한 내용, 확인하지 못한 내용, 검증 상태, 연결된 work_id/결과물 버전을 기록한다.
외부 URL은 열어 확인한 경우만 verified다. 검색 요약·AI 기억·존재만 확인한 URL은 검증이 아니다. 내부 데이터도 해당 파일과 정확한 범위를 실제로 읽어야 한다.

## 영상 벤치마크

업무 기본 목표는 관련 실제 사례 3~5개이며 무관한 사례로 숫자를 채우지 않는다. 원본 링크·게시자·게시일(확인 가능 시)·실제 본 구간·Hook/장면/자막/전환/CTA·참고 요소·우리 상품에 적용한 이유를 기록한다.
로그인·접근 문제로 영상 내용을 보지 못하면 미시청으로 표시하고 시각적 분석을 지어내지 않는다. 조회수·좋아요 관측시각을 남기며 공개 반응만으로 매출이나 Hook의 인과효과를 단정하지 않는다. 벤치마크는 형식 참고이지 상품의 진품·효능·인기·판매량 근거가 아니다.

## 상품 주장

상품 ID·SKU·옵션과 실제 데이터 범위를 연결한다. 일부 내부 판매로 전체 시장 '인기 TOP3'를 만들지 않는다. 판매 기준기간·수량/금액·취소/반품 처리·순위 기준을 명시한다. 소재·색상·로고·가격·재고·권리·광고 표현이 미확인이라면 해당 사실을 확정 카피에 넣지 않는다.

## 보고 구분

내부 진행·품의 문서에는 가정·미확인·대안을 별도 표시할 수 있다. 다만 미검증 항목을 확정 사실·검증 완료라고 표시하거나 그 위에 확정 결론을 쌓지 않는다. 근거 부족 때문에 최종 판단이 불가능하면 '보류/추가 확인 필요'가 결과다.
최종 검증 보고·게시용 결과는 실제 확인된 사실만 사용한다. 접근 불가·상충·부분 검증 주장을 제거했을 때 결론이 무너지면 출력/게시를 막는다. 의사결정에 필요한 질문을 보고하는 것과 미검증 주장을 최종 사실로 출력하는 것은 다르다.

## 분석 설명

'무슨 근거 → 어떤 기준 → 어떤 선택/대안 → 왜 이 초안'을 짧게 설명한다. 검색되지 않은 인용·임의 점수·가짜 사례·가짜 링크·예시 수치를 실무 실적으로 만들지 않는다. 비공개 사고과정이 아니라 재현 가능한 계산·관찰·판단 이유를 보고한다.
