# 부사수 Active Work

- Updated: 2026-09-06
- 원장: work/items/*.json
- 필터: assigned_to=assistant, work_status가 done/cancelled가 아닌 업무

현재 원장에 부사수로 명시 배정된 업무 없음. 기존 5개 업무는 담당자가 명시되지 않아 임의 배정하지 않았다. 대표님 아이디어 6건도 실제 지시 없이 active로 만들지 않았다.

새 요청을 접수하면 directive와 work_id를 만들고 담당·범위를 확인해 원장을 갱신한다. 전체 회사 업무는 working/CURRENT_WORK.md를 참고한다.
