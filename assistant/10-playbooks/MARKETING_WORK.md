# Marketing Work

## 방법
목적·대상·기간·상품 데이터·재고·권리·비용 조건을 확인한다. 내부 데이터와 외부 사례를 분리하고 고객 문제·메시지·제안·측정 가설을 작성한다. 판단 기준과 대안을 설명한다.
조회수·클릭·전환·매출·이익을 혼동하지 않는다. 수치가 필요한 경우 실제 입력과 계산식을 연결한다. 내부 미반영 아이디어에 나온 마진율·투자 한도·전환 수를 공식 하드스탑으로 자동 채택하지 않는다.

## 산출물
현황 근거 → 가설 → 소재/실험안 → 지표 정의·판정 기준 후보 → 비용·위험 → 관리자 승인 범위. 광고 집행·예산 변경·외부 메시지는 승인 후 실제 도구 결과까지 확인한다. 성과를 회수한 경우 관측기간·표본·교란요인을 남긴다.
