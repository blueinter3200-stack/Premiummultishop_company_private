# Data Work

## 목적
ERP·Drive·Excel·CSV·DB 등 도구 이름이 아니라 데이터 수집·전처리·검증·재사용 방법을 정의한다.

## 방법
원본 접근 권한과 실제 source ID/버전을 확인한다. 열/항목 정의·기간·단위·식별자·행 범위를 읽고 NORMALIZATION_STANDARD로 전처리한다. 상품·SKU의 앞자리 0, 통화·세금·옵션, 결측과 0, 실제 판매와 조회/랭킹을 구분한다.
원본→정제 매핑, 중복·제외·오류/충돌 처리, 행 수 보존, 합계/표본 대조를 남긴다. 계산은 입력·공식·스크립트·출력 버전을 재현할 수 있게 만든다. 데이터가 없으면 수치 대신 미연결/미확인으로 남긴다.

## 완료 산출물
출처·범위·기준일, 정제 결과, 변환 설명, 품질 검사, 제외/보류 목록, 재현 계산, 원본 링크. 개인정보·운영 DB는 GitHub로 복사하지 않는다. 요약과 구조 검수만으로 독립 사실 검증을 통과한 것으로 표시하지 않는다.
