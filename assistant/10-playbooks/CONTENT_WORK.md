# Content Work — 쇼츠·릴스·이미지·영상

## 순서

1. 지시 원문과 목적·상품·플랫폼·승인 범위를 확인한다.
2. 실제 상품 데이터와 이미지의 파일 ID·버전·시트/범위를 읽는다. 소재·색상·옵션·가격·재고·권리를 확인한다.
3. 관련 실제 숏폼 사례 3~5개를 목표로 조사하되 수량보다 관련성을 우선한다. 직접 본 링크·구간·게시자·관측시점, Hook·장면·자막·전환·CTA를 기록한다. 못 본 영상은 미시청으로 구분한다.
4. 사례별 참고 요소, 우리 상품에 적용한 이유, 적용하지 않은 요소를 작성한다. 유행이나 성과 인과를 근거 없이 단정하지 않는다.
5. 콘셉트 → 초 단위 스토리보드 → 화면/자막/내레이션/상품근거/사용 자산을 연결한다.
6. 승인된 제작 범위에서 이용 가능한 도구로 초안을 만들고 job·출력 파일·버전·검수 결과를 남긴다. Higgsfield 연결을 가정하지 않는다.
7. 원문·상품·벤치마크·판단·스토리보드·초안·미확인·결정 요청을 묶어 `assistant/40-handoff/to-jin/`에 상신한다.
8. 승인된 버전과 범위만 후속 실행한다. 결과 수락과 게시 승인은 다르다.

## 핵심 품질

관리자가 링크를 눌러 원본 상품과 벤치마크, 실제 초안을 대조할 수 있어야 한다. 생성 영상이 실제 상품의 로고·소재·형태를 변형하거나 미검증 상품 설명을 넣었으면 수정한다. 벤치마크 문구·영상·음원 자체를 무단 복제하지 않는다.

## 참고 수치 주의

이전 대화의 특정 브랜드 TOP3, '27개 중 4개' 등은 서식 예시다. 실제 조회 근거가 없으면 회사 데이터나 제작 실적으로 입력하지 않는다.
