# PMS 상세페이지 전환 시스템 v1.0

- 기준일: 2026-08-15
- 사업: Premium MultiShop
- 상태: 설계 완료 / 상위 5 SKU 실제 선정은 Cafe24·GA4·주문 데이터 필요

## 1. 핵심 정의

> 상세페이지는 디자인물이 아니라 온라인 영업사원이다.

PMS 상세페이지의 임무는 상품을 예쁘게 보여주는 것이 아니라 다음 순서로 구매 결정을 돕는 것이다.

```text
3초 이해
→ 고객 문제 인식
→ 해결 가능성 이해
→ 구매 후 효익 확인
→ 증거 확인
→ 위험 제거
→ 조건·스펙 확인
→ 행동
```

명품 상품은 일반 상품보다 다음 불안이 크다.

- 정품인가
- 가격이 합리적인가
- 실물 상태와 구성품은 정확한가
- 해외 주문·통관은 누가 책임지는가
- 반품·교환이 가능한가
- 구매 후 수선·A/S가 가능한가
- 문제가 생기면 판매자가 해결하는가

따라서 일반적인 예쁜 이미지·브랜드명·스펙 나열형 페이지보다 **효익·증거·책임·안심**을 앞에 배치한다.

## 2. 상위 5 SKU 선정 규칙

현재 공개 페이지로는 판매량·세션·전환율을 확인할 수 없으므로 실제 SKU를 임의 선정하지 않는다.

Cafe24·GA4·주문 원장에서 다음 방식으로 선정한다.

### 우선순위 점수

```text
상위 5 후보 점수
= 0.30 × 상품페이지 세션 정규화
+ 0.25 × 주문수 정규화
+ 0.20 × 장바구니수 정규화
+ 0.15 × 매출/세션 정규화
+ 0.10 × 기여이익 정규화
```

단, 다음은 후보에서 제외 또는 보류한다.

- 정품·통관·상품상태 증거 미확인
- 실제 재고·가격 불일치
- 판매 중지·품절·리드타임 불명
- 순마진 계산 불가
- 상품페이지 유입 데이터가 전혀 없음

### 실험군 구성

- READY 3개: 국내 실물·검수·빠른배송형
- RARE 2개: 해외 주문형·가격·희소성형

단순히 매출 상위 5개만 고르지 않고, 재고 유형별로 한쪽에 치우치지 않게 구성한다.

## 3. 상세페이지 10단계 구조

| 단계 | PMS 구성 | 핵심 질문 | KPI |
|---|---|---|---|
| 1. Main Hook | 고객의 불안·욕망 한 문장 | 왜 지금 멈춰야 하는가 | 첫 3초 이탈·스크롤 시작 |
| 2. Sub Solution | PMS가 해결하는 방식 | 그래서 무엇이 달라지는가 | 첫 25% 도달 |
| 3. Persona Problem | 상황·고민 3~5개 | 이 상품이 내 문제인가 | 체류·스크롤 깊이 |
| 4. Benefit | 구매 후 변화 | 사면 무엇을 얻는가 | 장바구니율 |
| 5. Proof | 검수·실사·구성품·증빙 | 판매자 말을 믿을 근거가 있는가 | 장바구니·상담 |
| 6. Risk Reversal | 배송·반품·통관·A/S | 문제가 생기면 어떻게 되는가 | CTA 클릭·문의 감소 |
| 7. Scarcity | 실제 재고·기간·조달 조건 | 왜 지금 결정해야 하는가 | 구매전환율 |
| 8. Feature | 사이즈·소재·원산지·구성 | 최종 확인할 정보는 무엇인가 | 옵션 오류·문의 |
| 9. CTA | 구매·상담·재고 확인 | 다음 행동은 무엇인가 | CTA 클릭·구매 |
| 10. FAQ | 정품·배송·반품·A/S | 마지막 불안은 무엇인가 | 이탈·상담·CVR |

## 4. READY 페이지 템플릿

### Main

```text
명품 온라인 구매, 실물을 보지 못해 불안했다면.
```

### Sub

```text
국내 창고 실물 확인, 출고 전 검수, 구성품과 배송 조건을 확인한 뒤 선택하세요.
```

### Problem

- 화면과 실제 색상이 다를까 걱정된다
- 구성품이 빠져 있을까 불안하다
- 정품 여부를 판매자 말만 믿기 어렵다
- 반품·수선이 필요할 때 판매자가 사라질까 걱정된다

### Benefit

```text
구매 전에 확인할 수 있고, 문제가 생기면 주문번호 하나로 Premium MultiShop이 처리합니다.
```

### Proof

- 상품 실물 사진
- 검수일·검수 상태
- 구성품 체크리스트
- 스타일코드·사이즈 정보
- 정품 관련 확보자료의 공개 가능 범위
- 재고 확인시각

### Risk Reversal

- 국내 실물 보유 여부
- 출고 예정일
- 국내 반품 주소
- 단순변심·상품불일치·오배송 처리
- A/S·수선 가능 범위
- 정품 분쟁 접수 절차

실제로 제공하지 않는 보장·A/S·보상은 문구에 넣지 않는다.

## 5. RARE 페이지 템플릿

### Main

```text
국내에서 쉽게 찾기 어려운 상품이라면, 가격보다 먼저 조달과 책임을 확인하세요.
```

### Sub

```text
해외 주문형 상품의 예상 조달기간·통관 조건·반품·환불 기준을 구매 전에 공개합니다.
```

필수 표시:

- 해외 주문형 여부
- 공급처 확인시각
- 예상 조달기간
- 예상 배송기간
- 통관 주체·관부가세 부담자
- 품절·가격변동 시 처리
- 해외 반품 가능 여부와 비용
- 구매대행·해외 주문형·국내 판매 구분

## 7. 증거 우선순위

1. 해당 SKU의 실물 사진·검수 기록
2. 해당 SKU의 구성품·상태·스타일코드
3. 해당 주문의 배송·출고 기록
4. 공급처 인보이스·거래증빙
5. 공식 제조·수입 자료
6. 실제 고객 리뷰·상담·재구매
7. 브랜드·플랫폼 일반 설명

일반 브랜드 설명을 해당 SKU의 정품 증거처럼 사용하지 않는다.

## 9. 측정 지표

### 기본 KPI

- 상품페이지 세션
- 3초 이탈률 또는 첫 스크롤 시작률
- 25%·50%·75%·90% 스크롤 도달률
- 상담 클릭률
- 장바구니율
- 결제 시작률
- 구매전환율
- 매출/세션
- 주문당 CM1·CM2
- 반품·취소율
- 배송 문의율
- 정품·상품불일치 문의율

### 계산식

```text
구매전환율 = 구매 주문수 / 상품페이지 세션
장바구니율 = 장바구니 생성수 / 상품페이지 세션
매출/세션 = 상품 귀속 매출 / 상품페이지 세션

상세페이지 개선 추가매출
= 상품페이지 세션 × (개선 CVR - 기존 CVR) × 평균 주문금액
```

금액 효과는 세션·기존 CVR·객단가가 들어오기 전까지 검증 불가다.

## 10. 테스트 방식

### 우선 권장: 전후 테스트

Cafe24 A/B 기능·트래픽 분할 권한이 확인되지 않으면 기존 버전을 보존하고 개선 버전을 일정 기간 적용한다.

필수 기록:

- 테스트 시작·종료일
- 세션 규모
- 유입 채널
- 가격·재고·배송 조건
- 기존·개선 페이지 버전
- CVR·장바구니율·매출/세션
- 반품·문의·기여이익

가격·재고·배송·광고를 동시에 바꾸면 상세페이지 효과를 분리할 수 없으므로 테스트 기간에는 가능한 한 고정한다.

### 성공 판단

- CVR만 증가하고 CM1·CM2가 감소하면 실패
- 장바구니율만 증가하고 결제율이 감소하면 불안 제거·가격·배송 조건 재검토
- 문의가 증가해도 상담 후 구매율·CM2가 개선되면 긍정적일 수 있음
- 매출보다 주문당 기여이익과 매출/세션을 함께 본다

## 11. AI 상세페이지 Agent 흐름

```text
상품정보 수집
→ 고객·경쟁·검색 신호 분석
→ Persona Problem 추출
→ Main/Sub Copy
→ Feature-Benefit 변환
→ Proof 자료 목록화
→ Risk Reversal FAQ
→ CTA
→ Cafe24 초안
→ 사람 검수
→ 등록
→ 전환 데이터 수집
→ 개선안 생성
→ 사람 승인
```

AI가 만들어서는 안 되는 것:

- 정품 보장 사실
- 재고 수량
- 배송일
- 관세·부가세 포함 여부
- A/S 가능 여부
- 반품 가능 여부
- 할인·희소성
- 고객 리뷰·판매실적

모든 사실은 상품·주문·정책 원장에서 주입하고, 출처 ID를 표시한다.
