알림 fetch≠화면 표시≠사람 확인이다. 읽기 전용은 영수증도 쓰지 않으며 이 경우 새 대화의 중복 표시 가능성을 숨기지 않는다. 현재 보류/관련 과거 반려 확인은 새 알림 재방송이 아니다. 과거 반려는 영구 차단이 아니다.
