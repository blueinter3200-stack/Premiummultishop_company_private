## 발견·처리

기존 pending index는 실제 saved 아이디어 6건 중 2건 누락이었다. 원기록 상태는 건드리지 않고 6건 인덱스로 복원한다.
아이디어 6건을 출처 commit/blob·원문 위치·기준일·작성자·계획 수치·미정·권위가 분리된 JSON으로 구조화한다. 첨부 정제본 2건에는 출처·원본 결손·주장 검증 수준 메타데이터를 추가한다. 원문 6개와 기존 첨부 정제본 2개의 본문은 변경하지 않는다.
현재 업무판의 기존 5개 업무를 ID가 있는 원장으로 연결하고 원문 전체를 같은 blob으로 보존한다. 오늘 새로 요청된 운영체계 배포 업무를 별도 1건 기록한다. 실제 담당·기한·완료를 추정하지 않는다.

역할·방법·지시·상태·결과·결재를 분리한다. 개별 work가 상태 원장이고 ACTIVE/CURRENT_WORK는 파생판이다. 승인 범위·결과물 버전·실제 근거를 연결한다. main 저장만으로 회사 공식화·게시·실행 완료가 되지 않는다.
